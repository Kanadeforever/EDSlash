# EDSlash 项目说明

> 当前接续（2026-10-02）：统一DisplayFix＋QOL＋Controller、TOML及静态SDL3.4.16；用户确认性能候选1掉帧缓解、功能正常、实机验收通过。build.bat现在一次输出发行EDSlash.asi与debug/EDSlash_debug.asi，优化相同、运行段一致，UPX仅处理发行副本。MOD设置界面后置，未来F12和L3＋R3。最新配置／构建／验收见《统一配置与基础迁移说明.md》《完整接档说明.md》；下文旧阶段保留历史，不扩为所有设备或新产物全部实机。

EDSlash 是《刀剑封魔录》与《刀剑封魔录外传：上古传说》的统一现代化工程。本文恢复旧项目介绍中的入口信息，并按 2026-10-01 当前 source 核对；不是旧版本发布声明。

主插件发行名为 release/BladeSwordQOL.asi 与 BladeSwordQOL.ini，包含 DisplayFix 和 QOL。DisplayFix 提供宽屏、HUD／辅助 GUI 层级与字体 DPI 兼容；QOL 提供地面名称常显和分级自动拾取。

Controller 属于同一工程，源码在 source/src/Modules/Controller，当前仍独立构建为 EDSlashController.asi，配套 EDSlashController.ini 和 SDL3.dll。当前源码版本为 v0.1-dev9，支持两份非 Steam 本体 1.05／外传 2.01 基线。dev8／dev9 的必杀、方向闪避、拾取文字、全向格挡和图标显示已有分项用户确认；这些不能扩大为两作全部功能全面验收。LB药品仍暂假定通过，完整界面操控仍未实现。

构建入口与依赖说明统一见[源码构建说明](../source/readme.md)，不另外建立构建说明。完整架构、地址、成功／失败路线、验证边界、阻塞项和下一步见[完整接档说明](完整接档说明.md)。QOL 功能见[自动拾取与地面物品名称说明](自动拾取与地面物品名称说明.md)，当前手柄规则见[手柄快捷施放与体力规则说明](手柄快捷施放与体力规则说明.md)。

项目许可证为根目录[LICENSE](../LICENSE)中的 MIT 正文，SDL 许可单独见[SDL第三方许可](SDL第三方许可.txt)。本轮没有修改许可证或根 README。
