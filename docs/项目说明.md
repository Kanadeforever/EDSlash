# EDSlash 项目说明

EDSlash是《刀剑封魔录》和《刀剑封魔录外传：上古传说》的统一现代化模组，整合DisplayFix、QOL与Controller。当前工作重心是手柄原生操控；本体1.05与外传2.01的Steam／非Steam四份准确基线同时支持；手柄入口四样本离线核对通过，Steam实机仍待验收。

生产为单个EDSlash.asi，配置EDSlash.toml、日志EDSlash.log，SDL3.4.16静态链接。发行在release根，完整版在release/debug，实际安装只取一种。唯一本地构建说明为[source/readme.md](../source/readme.md)，不另造构建入口。

手柄已实现连续方向移动、原生战斗及自定义套组、技能/投掷直接发动、防御/体力/方向闪避、必杀准备确认和物理输入交接。菜单已接通标题/系统/确认取消、读档删除、NPC、日志分类/列表、技能学习/连招编辑，使用独立焦点和原生操作；技能/日志已有当前测试通过反馈，未逐作列明，删除补位修复仍待实机。创建/设置内部页、装备区域、自有MOD设置后置；双扳机原动作菜单选择/设置已有准确Steam外传实机确认，十二快捷格动态框及Back丢弃/肩键收敛待实机；六物品区、空尾页恢复和持有中心图样已实现，两作实际效果待验收。既有实机确认不能扩大到新增功能。

完整架构、地址、稳定方案、失败教训和接续见[完整接档说明](完整接档说明.md)，菜单操作与验收见[手柄首批菜单实现与验证说明](手柄首批菜单实现与验证说明.md)，页面覆盖见[菜单需求清单](手柄菜单操控需求清单.md)。配置见[统一配置与基础迁移说明](统一配置与基础迁移说明.md)，历史提交、散列和逐轮验证只存[版本与更新记录](版本与更新记录.md)。
