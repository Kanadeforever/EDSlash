# EDSlash 项目说明

EDSlash 是《刀剑封魔录》与《刀剑封魔录外传：上古传说》的统一现代化工程。本文恢复旧项目介绍中的入口信息，并按 2026-10-01 当前 source 核对；不是旧版本发布声明。

主插件发行名为 release/BladeSwordQOL.asi 与 BladeSwordQOL.ini，包含 DisplayFix 和 QOL。DisplayFix 提供宽屏、HUD／辅助 GUI 层级与字体 DPI 兼容；QOL 提供地面名称常显和分级自动拾取。

Controller 属于同一工程，源码在 source/src/Modules/Controller，当前仍独立构建为 EDSlashController.asi，配套 EDSlashController.ini 和 SDL3.dll。当前源码版本为 v0.1-dev7，支持两份非 Steam 本体 1.05／外传 2.01 基线；新快捷施放、投掷、独立套组和体力规则仍待两作实机。闪避已有失败反馈，尚未修复。

构建入口与依赖说明统一见[源码构建说明](../source/readme.md)，不另外建立构建说明。完整架构、地址、成功／失败路线、验证边界、阻塞项和下一步见[完整接档说明](完整接档说明.md)。QOL 功能见[自动拾取与地面物品名称说明](自动拾取与地面物品名称说明.md)，当前手柄规则见[手柄快捷施放与体力规则说明](手柄快捷施放与体力规则说明.md)。

项目许可证为根目录[LICENSE](../LICENSE)中的 MIT 正文，SDL 许可单独见[SDL第三方许可](SDL第三方许可.txt)。本轮没有修改许可证或根 README。
