# 手柄模块接档说明

> 文档维护约定：本文按主题维护当前有效的技术正文，不再追加版本更迭、日期同步或发布补丁章节。版本变化、旧版散列、阶段测试与用户反馈统一记入[版本与更新记录](版本与更新记录.md)；技术结论变化时直接修订对应正文。

## 模块定位与源码入口

Controller位于source/src/Modules/Controller，由ControllerModule.c接入统一ModuleRegistry。生产只有Main.c的ASI入口，静态SDL3.4.16统一链接；配置与日志共用EDSlash.toml/EDSlash.log。工具在source/tools/controller，唯一构建说明为source/readme.md。

| 单元 | 职责 |
|---|---|
| ControllerModule.c | 游戏线程内采样桥、延后SHA/动作桥/SDL初始化、配置同步 |
| Profile.c / ProfileData.h | 两作散列、地址、结构偏移和签名；元数据来自profiles.json |
| Input.c / Control.c | 静态SDL采样、设备映射、来源判定、组合层、圆形死区与等距投影 |
| Game.c | 原生动作/移动/交互适配、角色与世界上下文 |
| Menu.c / Menu.h / ActionMenu.c | 公共路由、标题/读档/删除确认/系统/资金独立焦点与原生业务 |
| Cursor.c / Inspect.c | 注册Runtime焦点提供者、原持有图标锚点，360度近身调查、原左键交互分流及世界悬停隔离 |
| Combat.c / SkillResolver.c | 选择码到Method、请求/实际通知、历史、短重试、Y右手动作与独立套组 |
| Guard.c | 原生防御、体力、方向闪避、真实动作安全点与应用确认 |
| Crash.c / Crash.h | 异常地址/寄存器与最近阶段文本记录，不吞异常，不附加进程 |
| Feedback.c | 既有模式反馈；不等同完整命中/格挡反馈体系 |

## 双游戏要求

同一ASI同时面向本体1.05与外传2.01的Steam／非Steam四份准确基线，地址、ABI、偏移、签名、角色差异和测试成对维护。未知样本或签名失配停止对应功能，不借另一作地址。四份完整SHA和局部签名分别验证，不能用同一游戏的另一发行版替代准确散列；新增Steam实机仍待验收。

## 当前操作

左摇杆移动，L3切走跑，松杆停止；已认可的圆形死区、前探和请求去重保持。A调查交互，X当前左手动作，Y当前右手技能或自定义连招；当前世界层没有独立B翻滚分派，菜单A不注入Enter。

LT防御，LT+左摇杆直线方向闪避；默认单LT+Y/B/A/X切1/2/3/4套，新模式可配置为十字；旧模式固定十字切套组、单LT面键必杀。双扳机面键必杀首次准备、同键再次新按释放。RT14技能槽直发，RB六槽投掷，LB药品沿用业务。普通十字键与Start/R3保留既有页面/小地图入口。

BACK+START进入主动鼠标模式，左杆移动鼠标、右杆速度为三分之一、LT右键/RT左键；模式反馈200/1500毫秒。物理输入交接保留已成功动作历史与进度，失焦/断线/切图清理自有来源，层切换等待旧按键释放。

## 战斗与显示

普通手柄独立解析技能与目标，提交原生协议，保留原资格、距离、消耗、碰撞与执行器。RT/RB不改变Y永久选择和游标；实际套组步骤成功才推进。新边沿可以接管等待请求，有限重试有期限。

全向格挡只接管当前玩家有效防御，保留最低5点体力门与特殊穿防。体力幅度按最大体力百分比；直线闪避分段检查地图格和占用，遇障碍停止。动作图标保留到收尾动画结束；拾取提示属于QOL。

## 设置安全应用与验证

Guard_IsDodging读取当前有效角色状态17。输入释放、无活动Runtime且不在闪避时才给动作设置安全点；Guard_ApplySettings确认完整接收后消费generation，否则下一帧继续。正常无候选帧不重复玩家解析或磁盘读取。

基础迁移与性能已有用户实机确认，设置热保存应用待实际保存链验证。用户对此前菜单/调查/技能日志反馈基本正常，未逐作列明。日志/读档补齐、空尾页恢复、六物品区域A原操作/X切页/Y切区/B取消持有及中心图样已双版离线通过，详情/持有图样/堆叠/物理交接/性能待两作实机。必杀由原同组条件满足后自动学习。装备区域及其它未实现页、自有MOD设置和全设备覆盖后续。地址、操作与边界见对应说明。

max_distance在统一TOML，默认160，16～480。NPC A不依赖鼠标配对2C4，原时间保护/外传冷却保留；对白按住A加速原滚动。出口区域内新按A触发20，进入不自动换区。

## 世界快捷与移动目标

R3在世界玩家有效时允许GAME/MENU层走原Tab小地图入口，菜单仍独占A/B及导航，RT组合层不追加Tab。连续摇杆远目标经过原地图通行资格的有界直线检查，墙前缩短、第一格被挡则不启动原绕路。原速度、最终寻路、动态占用和碰撞保留。日志可自动给出世界位置和请求/有效目标；实际复杂墙角手感仍待验收。

当前焦点显示：快捷格、物品格、技能图标及左右手动作菜单使用Runtime原投掷动态框；裁取只取源片段，按安全边缘拼接成目标大小，并补偿动画原点。持有物品沿原光标图标居中，非格子按钮／确认项原指针保持。道具箱Back调用原物品编号丢弃，空格不动作；LB/RB仅日志和招式有效，连招X上下区/Y套组符合聚焦语义。外传Steam默认360度、面键套组、动作菜单选择/设置已确认；新动态框/Back/肩键和准确计时待实机，首次复制存档贴图丢失归因未定。

共享框已移到Runtime/Focus.c，Controller格子/技能图标只提供矩形及优先级，按钮/确认项不请求框，不解析/画素材。每帧失效和素材不可用的原反馈保持，持有图标仍中心；迁移后实机待验收，见《运行时焦点提示服务与格子界面说明.md》。

普通世界B按住预览／松开跳跃，左杆定方向、原基础动作数据映射、原距离和执行资格、软件落点及既有图标保持详见《手柄跳跃与落点预览说明.md》；真实长老映射与新视觉待实机。设置／新游戏界面后续。

B技能预览扩散速度由[controller.skill_aim].expand_time_ms调整：默认1000毫秒，100～10000，越小越快。原技能最远距离不改，本次按B固定时长，保存后下次预览读取新值。源码及双发布TOML自动同步新键并保留已有设置；操作与边界见《手柄跳跃与落点预览说明.md》。
