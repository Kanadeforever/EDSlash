# 手柄模块接档说明

> 文档维护约定：本文按主题维护当前有效的技术正文，不再追加版本更迭、日期同步或发布补丁章节。版本变化、旧版散列、阶段测试与用户反馈统一记入[版本与更新记录](版本与更新记录.md)；技术结论变化时直接修订对应正文。

## 模块定位与源码入口

Controller位于source/src/Modules/Controller，由ControllerModule.c接入统一ModuleRegistry。生产只有Main.c的ASI入口，静态SDL3.4.16统一链接；配置与日志共用EDSlash.toml/EDSlash.log。工具在source/tools/controller，唯一构建说明为source/readme.md。

| 单元 | 职责 |
|---|---|
| ControllerModule.c | 游戏线程内采样桥、延后SHA/动作桥/SDL初始化、配置同步 |
| Profile.c / ProfileData.h | 两作散列、地址、结构偏移和签名；元数据来自profiles.json |
| Input.c / Control.c | 静态SDL采样、设备映射、来源判定、组合层、圆形死区与等距投影 |
| Game.c | 原生动作/移动/交互适配、角色与世界上下文 |
| Combat.c / SkillResolver.c | 选择码到Method、请求/实际通知、历史、短重试、Y独立套组 |
| Guard.c | 原生防御、体力、方向闪避、真实动作安全点与应用确认 |
| Feedback.c | 既有模式反馈；不等同完整命中/格挡反馈体系 |

## 双游戏要求

同一ASI同时面向非Steam本体1.05与外传2.01，地址、ABI、偏移、签名、角色差异和测试成对维护。未知样本或签名失配停止对应功能，不借另一作地址。Steam手柄适配后置，外传不后置。

## 当前操作

左摇杆移动，L3切走跑，松杆停止；已认可的圆形死区、前探和请求去重保持。A调查交互，X当前左手动作，Y当前自定义连招，B翻滚；菜单A不注入Enter。

LT防御，LT+左摇杆直线方向闪避；LT+上/右/下/左切第1/2/3/4套，回首项。LT+ABXY对应四个必杀，首次准备、同键再次新按释放。RT14技能槽直发，RB六槽投掷，LB药品沿用业务。普通十字键与Start/R3保留既有页面/小地图入口。

BACK+START进入主动鼠标模式，左杆移动鼠标、右杆速度为三分之一、LT右键/RT左键；模式反馈200/1500毫秒。物理输入交接保留已成功动作历史与进度，失焦/断线/切图清理自有来源，层切换等待旧按键释放。

## 战斗与显示

普通手柄独立解析技能与目标，提交原生协议，保留原资格、距离、消耗、碰撞与执行器。RT/RB不改变Y永久选择和游标；实际套组步骤成功才推进。新边沿可以接管等待请求，有限重试有期限。

全向格挡只接管当前玩家有效防御，保留最低5点体力门与特殊穿防。体力幅度按最大体力百分比；直线闪避分段检查地图格和占用，遇障碍停止。动作图标保留到收尾动画结束；拾取提示属于QOL。

## 设置安全应用与验证

Guard_IsDodging读取当前有效角色状态17。输入释放、无活动Runtime且不在闪避时才给动作设置安全点；Guard_ApplySettings确认完整接收后消费generation，否则下一帧继续。正常无候选帧不重复玩家解析或磁盘读取。

基础迁移与性能已有用户实机确认。设置热应用完成真实TOML/双游戏宿主与离线构建验证，待实机。LB药品暂假定；完整原生菜单、LT右摇杆左键菜单、自有设置页、自绘焦点、持续技能名单和全部设备覆盖未完成。原生接口地址见《手柄原生事件拆分方案.md》《逆向工程知识库.md》，测试见《手柄实机验证说明.md》。
