# 手柄跳跃与技能落点预览说明

## 共用技能路线

B只是在普通世界层增加技能落点预览，解析／资格／短缓冲／原动作协议／成功通知／图标动画均复用已可用的RT技能路线。没有独立ACTION_JUMP来源，没有硬编码Method或另取组首成员。

Game的skill_choice统一读取快捷选择：RT使用当前槽自定义配置或原绑定；B固定使用原第一槽，即默认RT+A所读的Q绑定，保持固定基础动作含义，不随MOD改绑RT+A改变。读取Q是查询原HUD+ C18链中的选择码，不是注入键盘事件。循环有界，未就绪则明确拒绝。

Combat_PreviewSkill复用resolve_request及first_usable；正式松键调用Combat_RequestSkillPoint，沿ACTION_SKILL传选择码和左右手风格，只增加point_request／requested_point。Combat_Update继续原Skill_Resolve、起手回退、资格与有限重试；显式点强制走opcode10，不能改为锁定敌人或鼠标点。预览不直接执行技能或消费资源。

## 按住预览，松开提交缓存点

普通世界层新按B进入预览，取消普通走路；左摇杆控制方向，回中保留方向，未推杆时反查原Facing。近身起点32世界单位（原上限更小则取上限），按[controller.skill_aim].expand_time_ms匀速扩到原method_range距离档×64，继续按住保持。expand_time_ms默认1000，范围100～10000毫秒，越小越快；每次新按B复制本次时长，途中保存新值只影响下次预览。原有效档本体423F40／外传42CAB0；不能把裸距离0当成无有效档。

按住阶段保存世界身份、Actor句柄、技能选择、方向及世界目标点，软件鼠标图样指示同一缓存点。松B先消费缓存点，再退出预览并提交共用技能请求；不在松键当帧重算方向／距离，避免新杆输入或多过一帧时钟改变已经显示的点。

预览期间不兼办普通移动／调查／X/Y攻击。菜单B、LT/RT/LB/RB组合B保留原规则，切层／失焦／断线／切图／角色变化／活动动作接管取消预览，不积压自动补跳。最终合法性、硬直、消耗、距离模式和碰撞仍由原技能Runtime处理，不直接写Actor位置。

## 指示与既有图标

Game_JumpAnchor用原projection函数取屏幕0点及两条单位轴，反解原相机投影；只替换软件指针绘制坐标，不改真实鼠标或MouseManager。松键／取消后隐藏预览指针。

Feedback_HoldSkill沿ACTION_SKILL临时图标通道保持预览选择，松键撤预览。成功动作继续Feedback_Start及Runtime结束／原动画收尾，最后恢复之前右手槽位；没有修改长期装备或另加固定图标倒计时。

## 对象边界与验证

场景Actor提供当前位置、Facing、活动Runtime及执行资格；玩家档案由原PlayerManager getter取得，Actor+308不能被当成档案初始化记录。B的共用快捷路线完全不读该init字段。该区别也应在后续设置界面角色绑定的数据来源核对中维持。

test_game --jump在Actor+308为空时提供可用的原快捷绑定，先走RT+A再在相同初始历史下走B，对照真实Method；普通与≥10000选择、两种左右手风格、近/远/封顶、松键只一次、松键改变杆／时钟仍用显示点、组合取消与图标收尾均回放。--jump-zero额外模拟裸距离0但原档有效。角色实际跳跃／长老瞬移与障碍资格仍待实机，这些宿主数据不冒充真实角色资源。

输入链含原始按钮／有效持键／新按；技能预览拒绝、预览选择／Method／距离档和松B缓存点提交有日志。当前地址、冻结EXE及原证据见《手柄跳跃与焦点图层原始证据.txt》，工具随源码位于[source/tools/工具说明.md](../source/tools/工具说明.md)，历史及身份见《版本与更新记录.md》，完整接档见《完整接档说明.md》。

配置示例：

```toml
[controller.skill_aim]
# 扩到最远落点所需毫秒；250更快，2000更慢，默认1000。
expand_time_ms = 1000
```

用户已确认共用技能路线的B实际运行正常、符合预期；未逐作／角色列明，不能扩大为所有场景通过。扩散耗时配置及在途固定仍以新的离线回放／后续实机为边界。
