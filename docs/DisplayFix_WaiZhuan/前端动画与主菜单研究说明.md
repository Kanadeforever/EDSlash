# 前端动画与主菜单研究说明

外传历史宽屏 EXE 与原版对比显示，游戏标题并不是靠永久改写整个程序为宽屏来实现。原版启动路径在 `0x0040C339` 明确准备 mode 4，并在 `0x0040C345` 调用同一个显示模式函数 `0x0040BCC0`。

因此当前设计遵循原游戏：

- 开场 / 标题 / 主菜单：保持原版 FRONTEND profile；
- 进入 Strategy state 3：才切到 GAMEPLAY profile；
- 离开 Strategy：先完成原版清理，再恢复前端代码配置并强制 mode 4。

这样做的理由来自本传已经实机验证的失败链：仅仅“恢复代码立即数”不会把已经存在的宽屏 DirectDraw Surface 自动变回 4:3；返回标题时必须真正重建前端 Surface。

外传是否所有固定分辨率动画都完全遵循同一生命周期，仍需 test1 实机验证。
