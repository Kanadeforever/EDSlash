# 前端动画与主菜单研究说明

外传历史宽屏 EXE 与原版对比显示，游戏标题不是靠永久改写整个进程为宽屏来实现。原版启动路径在 `0x0040C339` 明确准备 mode 4，并在 `0x0040C345` 调用显示模式函数 `0x0040BCC0`。

当前设计严格遵循原游戏自己的生命周期：

- 开场 / 标题 / 主菜单：保持 FRONTEND 原版 4:3；
- 进入 Strategy state 3：切到 GAMEPLAY 宽屏；
- 离开 Strategy：先执行原版清理，再恢复 FRONTEND profile，并强制原版 mode 4 重建 Surface。

这个设计已经在 v0.1-test1 由用户实机确认：标题保持 4:3，进入游戏后宽屏，返回主菜单后真实显示重新回到 640×480。

关键运行日志：

```text
[RUNTIME] Strategy enter original apply finished live=854x480 expected=854x480 force=1
[RUNTIME] Strategy exit old_state=3 FRONTEND profile=restored reset_mode=4 result=1 live=640x480 expected=640x480
```

因此当前不再追求“标题和游戏内始终保持同一个逻辑分辨率”。标题阶段恢复游戏原始行为、只处理游戏内分辨率，是已经实机验证的稳定方向。
