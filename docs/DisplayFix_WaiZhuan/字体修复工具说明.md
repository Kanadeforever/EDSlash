# 字体修复工具说明

## 独立工具位置

```text
source\FontFix_WaiZhuan\apply_dpi_font_fix.py
source\FontFix_WaiZhuan\apply_fix.bat
```

独立工具不会用整个 EXE SHA-256 当兼容白名单，而是验证外传真正的字体 DPI 机器码上下文。

## 已确认机器码

原始 CALL：

```text
FF 15 54 10 55 00
```

对应 `call dword ptr [0x00551054]`，也就是 `GDI32!GetDeviceCaps`。

替换为：

```text
83 C4 08 6A 60 58
```

含义：

- `add esp,8`：补回原 stdcall 会执行的参数清理；
- `push 96 / pop eax`：模拟 API 返回 96 DPI。

## 实机结论

v0.1-test1 已由用户确认：高 DPI 字体修复在外传正常工作。

## v0.1-test2 配置语义修复

ASI 内置字体修复和 `[Display] Enable` 现在完全独立。

允许：

```ini
[Display]
Enable=0

[Font]
FixDPI=1
```

只应用字体 DPI 修复，不安装宽屏 / HUD / 输入补丁。

这次修复没有改变字体目标机器码，因此独立 `FontFix_WaiZhuan` 工具本身无需改算法。

已离线验证：疑似原版和历史宽屏 EXE 都能通过目标内容检查，因此可以与旧静态宽屏 EXE 共存。
