# 字体修复工具说明

## 独立工具

```text
source\FontFix_WaiZhuan\apply_dpi_font_fix.py
source\FontFix_WaiZhuan\apply_fix.bat
```

独立工具按机器码上下文识别，不使用整个 EXE SHA-256 白名单。

## 已确认机器码

原始 CALL：

```text
FF 15 54 10 55 00
```

即 `call dword ptr [0x00551054]`，对应 `GDI32!GetDeviceCaps`。

替换：

```text
83 C4 08 6A 60 58
```

含义：`add esp,8` 补回 stdcall 参数清理；`push 96 / pop eax` 模拟 96 DPI 返回值。

## 实机结论

- v0.1-test1：高 DPI 字体修复实机通过；
- v0.1-test2：`Font.FixDPI` 与 `Display.Enable` 完全解耦；
- v0.1-clean1：字体代码完全沿用 test2，没有引入 test3~test9 Steam/影片实验。

允许：

```ini
[Display]
Enable=0

[Font]
FixDPI=1
```

这时只应用字体修复，不安装显示主线。
