# 字体修复工具说明

独立工具位于：

```text
source\FontFix_WaiZhuan\apply_dpi_font_fix.py
source\FontFix_WaiZhuan\apply_fix.bat
```

它不会用整个 EXE SHA-256 当兼容白名单，而是验证外传真正的字体 DPI 机器码上下文。

已确认原始 CALL：

```text
FF 15 54 10 55 00
```

即 `call dword ptr [0x00551054]`，对应 `GDI32!GetDeviceCaps`。

替换为：

```text
83 C4 08 6A 60 58
```

含义：

- `add esp,8`：手工清理原 stdcall 的两个参数；
- `push 96 / pop eax`：模拟 API 返回 96 DPI。

已经离线验证：疑似原版 `ComeOn.exe` 和历史 `ComeOn1920.exe` 都能成功生成字体修复副本，说明该工具可以和旧宽屏静态 EXE 共存。
