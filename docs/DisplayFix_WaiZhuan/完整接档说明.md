# 《刀剑封魔录外传：上古传说》DisplayFix v0.1-clean1 完整接档说明

## 0. 当前总状态

`v0.1-clean1` 是一次有意的纯净回滚版：**代码主体回到 v0.1-test2，只从 v0.1-test4 单独移植已实机确认成功的 Steam `ResJM.Lib` 多语言最终兜底；文档知识保留并修正 test3~test9 的全部调查结论。**

当前已通过：

- 非 Steam：标题/主菜单 4:3；Strategy 游戏内 fixed-Y 宽屏；HUD/GUI 居中；右侧 6 个按钮；96 DPI；退出 Strategy 后恢复 4:3；
- `Display.Enable=0` 与 `Font.FixDPI=1` 可独立工作；
- Steam：上述大部分显示/HUD/字体主线曾实机正常；
- Steam 多语言：test4 的窄 `ResJM.Lib` callsite shim 已实机确认消除裸 `ResJM.Lib` 缺失弹窗。

当前明确未解决：

- Steam + cnc-ddraw OpenGL 崩溃；
- Steam 开场动画比例拉伸；
- Steam 官方启动器阶段与 ComeOn.exe 阶段的真实职责边界尚需用用户本地 launcher 进一步独立验证。

## 1. clean1 代码组成

基线：`v0.1-test2`。


明确没有移植：

## 3. 核心架构

### 3.1 显示生命周期

```text
FRONTEND 原版 4:3
    ↓ Strategy enter state=3
GAMEPLAY fixed-Y/auto-X
    ↓ Strategy exit
恢复 FRONTEND + 原版 mode 4 force=1
```

### 3.2 固定高度宽屏

```text
TargetWidth = round(BaseHeight × AspectWidth / AspectHeight)
```

调整为偶数。推荐 `BaseHeight=480/600`。

### 3.3 HUD

仅平移底部主 HUD 根节点；边缘 UI 保持贴边。顶部按钮通过已确认的 0x0B/0x0E、world press 防穿透和 global release fallback 维持原版行为。

### 3.4 字体

把 `GetDeviceCaps(LOGPIXELSY)` 路径替换成固定 96 DPI 返回；已实机通过。

## 5. test3~test9 累计失败/踩坑

- test3：把问题归咎于 delayed full JMM，禁用后仍找裸 `ResJM.Lib`；
- test4：语言 shim 成功；影片 helper 未解决拉伸/OpenGL；
- test5：ActiveMovie watchdog 无 runtime 命中；
- test6：MovieManager/export 所有权实验无有效命中；
- test7：把含 relocation 的绝对地址写进运行时签名，ASLR 后永远失配；
- test8：改成 RVA 后 patch 真正安装，OpenGL 仍崩，证明尾部 teardown 不是唯一根因；
- test9：游戏进程中硬隔离 DirectShow worker/export 仍不解决，说明此前进程/实例假设存在根本问题。

## 6. 重要知识修正

`ComeOn.dll` 内 DirectShow/WndProc/cleanup 地址仍是静态逆向事实，但不能继续把 **ComeOn.exe 进程内加载的 ComeOn.dll** 自动等同于 **Steam 启动开场动画的实际运行实例**。

后续启动链调查提示开场动画很可能在官方 launcher 阶段、ComeOn.exe 创建之前发生。这一条尚缺用户本地 launcher 的独立二进制验证，因此记录为高优先级待验证假设，不把任何外部模组/仓库实现固化进当前工程。

## 8. 构建与发布硬规则

- 源码目录固定 `source\DisplayFix_WaiZhuan`；
- 文档目录固定 `docs\DisplayFix_WaiZhuan`；
- release 严格只有 `DisplayFix.asi` 与 `DisplayFix.ini`；

- 不递归扫描 ARM64 LLVM；
- ASI PE32/i386、DLL、非零入口、`InitializeASI`、Import Directory=0；
- 代码文件名英文；代码内使用非常详细的简体中文行内注释；
- 文档文件名简体中文，唯一既有例外为用户认可的 `source\DisplayFix_WaiZhuan\readme.md`；
- 每个源码包/编译包都必须能独立接档；
- 文档更新时必须遍历全部文档同步结论。
