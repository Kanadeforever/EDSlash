### v0.2-test1 历史新增运行逻辑（已实机成功，但实际仅 callback neutralize 生效）

Steam `ComeOn.dll` 初始化已确认连续安装两条通用 Hook：

```text
RVA 0x54E8..0x54F9  CreateFileA -> callback RVA 0x3E30, len=7   [保留]
RVA 0x54FE..0x550D  CreateWindowExA -> callback RVA 0x2830, len=12 [隔离]
```

CreateWindowExA callback 在调用原函数后检查 class=`EDIT`，并通过 `SetWindowLongA(GWL_WNDPROC)` 安装 `RVA 0x26A0` 自定义 WndProc。动态 Hook 对象布局：`+0x30C target / +0x318 length / +0x31C dispatcher / +0x41C original trampoline`。

test1 扫描 Hook 对象后，把真实 `USER32!CreateWindowExA` 入口直接跳到 ComeOn 已经重定位好的 `+0x41C` trampoline；同时 neutralize callback `RVA 0x2841` 后处理，并尝试恢复已存在 EDIT 子类窗口。

这是有意激进的一轮：目标是“一刀排除/命中最高嫌疑功能组”，不是逐函数小修。

## 3. 核心架构

### 3.1 显示生命周期

```text
FRONTEND 原版 4:3
    ↓ Strategy enter state=3
GAMEPLAY fixed-Y/auto-X
    ↓ Strategy exit
恢复 FRONTEND + 原版 mode 4 force=1
```

### 3.2 固定高度宽屏

```text
TargetWidth = round(BaseHeight × AspectWidth / AspectHeight)
```

调整为偶数。推荐 `BaseHeight=480/600`。

### 3.3 HUD

## 13. v0.2-test2 实机失败与 v0.2-test3 class-atom 假说

### test2 实机结论

用户日志确认 test2 已成功安装 `RVA 0x2889` 的 EDIT WndProc 禁用补丁，但 OpenGL 仍崩溃。因此：

- 全局 `CreateWindowExA` Hook 不是必要根因（test1 已证明）；
- `SetWindowLongA(GWL_WNDPROC)` 也不是唯一根因（test2 已证明）；
- test1 成功与 test2 失败之间剩下的有效差异，是 callback 更早的 `lpClassName` 读取、字符串比较与 EDIT HWND 记录。

### 新发现：callback 不支持合法 class atom

原 callback `RVA 0x2841` 从 hook context `+0x2C` 取 `lpClassName`，只做 NULL 检查，然后在 `RVA 0x2854` 执行 `mov bl,[ecx]` 直接读取字符串。Win32 `CreateWindowExA` 允许 `lpClassName` 使用 `MAKEINTATOM(atom)`；此时高 16 位为 0、低 16 位是 atom，不是字符串地址。ComeOn.dll 缺少这一检查，因此兼容层若用 class atom 创建辅助窗口就会被非法解引用。

### test3 实现

在 `RVA 0x2841` 用 `E9 rel32 + NOP` 跳到 ASI naked trampoline。trampoline 重放被覆盖的 `mov ecx,[esi+2C] / add esp,8 / mov [esi+20],eax`，然后：

- `lpClassName == NULL`：跳 `RVA 0x28A1`；
- `0 < lpClassName < 0x10000`：记录 atom 计数并跳 `RVA 0x28A1`；
- `lpClassName >= 0x10000`：跳回 `RVA 0x284E`，继续官方 `EDIT` 比较、HWND 记录、`SetWindowLongA` 和旧 WndProc 保存。

因此 test3 比 test1 更窄，同时撤销 test2 对官方 EDIT 功能的破坏。进入 Strategy 后若曾命中 atom，会输出 `[RUNTIME] Steam CreateWindowExA class-atom guard hit count=... last_atom=...`。
