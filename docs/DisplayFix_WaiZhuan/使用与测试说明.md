# 使用与测试说明

## 安装

把 `release` 中的 `DisplayFix.asi` 与 `DisplayFix.ini` 放到当前 ASI Loader 会加载的同一目录。插件日志为同目录 `DisplayFix.log`。

## 当前实机基线

v0.1-test1 已由用户在非 Steam 版确认：

- 标题 / 主菜单保持 4:3；
- 进入游戏后宽屏；
- GUI / 主 HUD 正常居中；
- 右侧 6 个菜单按钮正常；
- 高 DPI 字体正常；
- 返回主菜单后恢复前端 4:3。

用户顺带在 Steam 版测试也确认绝大多数上述功能正常。Steam + cnc-ddraw OpenGL 的动画后闪退仍留作后续专项。

## 推荐配置

```ini
[Display]
Enable=1
BaseHeight=480
AspectRatio=Auto

[Font]
FixDPI=1

[GUI]
CenterMainHUD=1
```

BaseHeight 是内部逻辑高度，不是最终显示器输出分辨率。4K 显示仍建议游戏内部使用 480 / 600，再交给 cnc-ddraw 放大。

## v0.1-test2 新配置语义

`[Display] Enable` 与 `[Font] FixDPI` 已完全解耦。

如果只想修字体而不启用宽屏，可以写：

```ini
[Display]
Enable=0

[Font]
FixDPI=1
```

预期：

- 游戏显示、HUD、输入保持原版；
- 高 DPI 字体仍被固定到 96 DPI；
- 日志出现：

```text
[OK] font DPI path patched to 96 DPI
[INFO] Display.Enable=0; widescreen/HUD/input patches disabled; Font.FixDPI remains independent
```

如果同时 `FixDPI=0`，则 DisplayFix 不应修改任何游戏代码。

## 宽屏验收日志

进入游戏：

```text
[RUNTIME] Strategy enter state=3 GAMEPLAY profile=ready
[RUNTIME] Strategy enter original apply finished live=854x480 expected=854x480 force=1
```

退出游戏：

```text
[RUNTIME] Strategy exit old_state=3 FRONTEND profile=restored reset_mode=4 result=1 live=640x480 expected=640x480
```

## A/B

如果以后出现单独 HUD 问题，可以只改：

```ini
CenterMainHUD=0
```

做 A/B。不要同时更改 BaseHeight、AspectRatio、cnc-ddraw 后端等多个变量。

## Steam

Steam 目前只作为顺带验证，不作为非 Steam 主线的正式验收对象。D3D9 后端可用；OpenGL 在开场动画后闪退，最后再独立调查。
