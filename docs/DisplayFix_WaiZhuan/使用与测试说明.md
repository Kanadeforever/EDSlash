# 使用与测试说明

## 当前纯净工作版

`DisplayFix_WaiZhuan v0.1-clean1`

代码主体严格回到 `v0.1-test2`，只保留 test4 已实机通过的 `ResJM.Lib` 多语言最终兜底。没有 test3~test9 的影片/OpenGL实验运行代码。

## 安装

发行包只包含：

```text
DisplayFix.asi
DisplayFix.ini
```

放到当前 ASI Loader 实际加载脚本的目录。日志 `DisplayFix.log` 会写在 ASI 同目录。

## 推荐配置

```ini
[Display]
Enable=1
BaseHeight=480
AspectRatio=Auto

[Font]
FixDPI=1

[GUI]
CenterMainHUD=1
```

`BaseHeight=480` 或 `600` 是推荐值。更高值会真正扩大内部世界/FOV和 Surface，可能明显降低性能。

## 字体可以独立开启

```ini
[Display]
Enable=0

[Font]
FixDPI=1
```

此时只修 96 DPI 字体，不安装宽屏/HUD/输入补丁。这是 `v0.1-test2` 修复后的固定语义。

## 非 Steam 回归验收

- 标题/主菜单保持原版 4:3；
- 进入 Strategy state 3 后切目标宽屏；
- HUD/GUI 居中；
- 右侧 6 个菜单按钮可用；
- 返回主菜单恢复 4:3；
- 高 DPI 字体完整。

关键日志示例：

[RUNTIME] Strategy enter original apply finished live=854x480 expected=854x480 force=1

## Steam 多语言验收

Steam 目录实际只有：

```text
ResJM.Lib.chs
ResJM.Lib.cht
ResJM.Lib.eng
ResJM.Lib.jpn
```

clean1 正常启动时应出现：

```text
[OK] Steam multilingual ResJM.Lib CreateFileA fallback installed
[INFO] WaiZhuan Steam/ComeOn.dll detected; clean1 otherwise keeps the original test2 Steam timing
[INFO] No test3-test9 DirectShow/OpenGL/MovieManager/watchdog/teardown experiment is active
```

真正遇到裸 `ResJM.Lib` 请求时，应出现：

```text
[RUNTIME] Steam raw ResJM.Lib redirect -> ...\ResJM.Lib.chs result=OK
```

验收条件：不再弹缺少裸 `ResJM.Lib`；当前语言正常；已经带语言后缀的文件不能被二次追加。

## Steam OpenGL 当前状态

clean1 **没有修 OpenGL**，这是故意的。当前目标是拿到一个没有历史实验干扰的纯净工作基线。

已知：D3D9 其余功能正常；OpenGL 仍会崩；动画比例仍未修。用户会先自行测试外部模组是否改变 OpenGL 行为。若外部模组也不能解决，再从 clean1 开始独立调查，不再沿用 test4~test9 的错误进程假设。
