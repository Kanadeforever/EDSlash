# 使用与测试说明

## 安装

把 `release` 中的 `DisplayFix.asi` 与 `DisplayFix.ini` 放到当前 ASI Loader 会加载的同一目录。插件日志为同目录 `DisplayFix.log`。

## 首轮推荐配置

```ini
BaseHeight=480
AspectRatio=Auto
FixDPI=1
CenterMainHUD=1
```

第一轮不要先上 1080 内部高度。BaseHeight 是游戏内部逻辑高度，不是最终显示器输出分辨率；4K 显示仍建议先让游戏内部保持 480/600，再交给 cnc-ddraw 放大。

## 验收顺序

1. Windows 保持实际使用的非 100% DPI（例如 125%），不要打开“高 DPI 缩放替代：系统”。
2. 冷启动，观察开场与标题是否仍按原版 4:3 生命周期显示。
3. 进入游戏，检查世界是否扩展到目标宽度。
4. 检查底部 HUD 是否居中、小地图/右侧 UI 是否仍贴边。
5. 检查字体是否完整，无裁切。
6. 返回主菜单，确认真实 Surface 恢复前端 4:3，而不是留在宽屏。
7. 再进入一次游戏，确认可以重复切换。
8. 把完整 `DisplayFix.log` 回传。

## 关键预期日志

进入游戏应看到类似：

```text
[RUNTIME] Strategy enter state=3 GAMEPLAY profile=ready
[RUNTIME] Strategy enter original apply finished live=854x480 expected=854x480 force=1
```

退出应看到类似：

```text
[RUNTIME] Strategy exit old_state=3 FRONTEND profile=restored reset_mode=4 result=1 live=640x480 expected=640x480
```

如果 live 宽高与 expected 不一致，不要继续把 GUI 错位当成 HUD 问题，先按分辨率生命周期失败处理。

## A/B

若宽屏和字体正确，但 HUD 有异常，只改：

```ini
CenterMainHUD=0
```

做一次对照。不要同时改 BaseHeight、AspectRatio 和 cnc-ddraw 后端，避免一次改变太多变量。
