## 统一框架与输入时序

主入口src/Main.c只启动一次Runtime。Runtime统一识别PE身份、建立日志／配置／公共输入帧，Registry注册DisplayFix、QOL、Controller三个模块。Controller独立DllMain／InitializeASI已移除。公共Hook身份为15项（含Controller菜单焦点、软件光标与调查悬停归属）；Controller的其他业务钩子继续在其模块内验证和安装，局部签名数量不等于Hook数量。

Controller从Runtime取得游戏身份，保留两作Steam／非Steam四份准确EXE SHA和局部签名门。PE不匹配或真实基址不是0x400000时不访问固定游戏地址。未知宿主和重定位加载测试通过。模块表的成功仅代表初始化返回值；Controller首次注册只是采样桥成功，完整SHA、SDL及动作桥延后到Loader锁外的游戏输入线程。SDL失败与没有连接设备分开，失败撤回采样并释放自己的SDL引用；ControllerModule_IsReady仅表示全部就绪。公共输入帧在未ready时接收idle候选，ready时继续等待Guard安全点，不能用Registry登记阻断失败后的候选应用。公共输入帧失败时QOL停止，显示和Controller仍独立尝试；配置损坏则不启动业务，不覆盖坏文件。

事件的实际边界：

| 事件 | 提供者及含义 |
|---|---|
| INPUT_FRAME_BEGIN／END | Runtime包围原input_update；subject是原输入管理对象，不应当作256字节键盘缓冲写入 |
| INPUT_SAMPLED | Controller原GetKeyboardState返回后完成设备／来源采样；subject是真实键盘缓冲 |
| INPUT_RESOLVED | 原鼠标resolver返回后、Controller Game_Update之前；subject为原鼠标管理对象 |
| GAMEPLAY_ENTER／EXIT | 既有显示后端的场景切换边界，仍受其运行条件影响 |
| UI_DRAW_BEGIN／END | 原UI manager Draw前后；END后仍可能有延迟GUI补画 |

不同物理入口按原调用位置保留。INPUT_FRAME_END只表示原input_update返回，不保证Controller业务已执行；不能把它解释成整个世界逻辑帧结束。QOL在该结束事件同步参数并执行扫描，保持原QOL的实际调用位置。普通手柄仍走已验收原生业务，不改变真实鼠标；主动鼠标模式保留既有救援流程。

调查距离键[controller.interaction] max_distance默认160，16～480世界单位，360度近身、前方优先，原对象资格保留。游戏读取已有TOML缺项时仍用默认；手改文件需重启。正式构建在发行/debug及本轮可选upx配置补模板新段和键，原值、技能绑定与注释保留，语法损坏不覆盖；checks-only不写发布。此构建同步不是游戏内热保存，也不自动部署到安装目录，详见唯一构建说明source/readme.md。

## TOML与全部设置

新模板由Runtime/Config.c描述表生成，运行时默认与构建默认使用同一来源。全部行为设置由描述表生成，另含meta.schema和默认技能来源；14个技能槽使用原游戏来源或角色独立绑定。

| 分组 | 键与含义 |
|---|---|
| meta | schema=1，仅支持最终格式，不维护旧MOD配置升级链 |
| display | enabled；base_height默认480、必须正整数；aspect_ratio为auto或正整数宽:高，保留8像素宽度对齐 |
| font | fix_dpi，默认启用 |
| gui | center_hud、auxiliary_above_hud，默认启用 |
| qol.ground_items | always_show_names，默认true |
| qol.auto_pickup | mode=2，0关闭／1钱／2加回复／3再加宝石护身石／4全部；interval_ms=100、drop_delay_ms=1000，范围0..3000 |
| controller | enabled，默认true，世界功能启停在输入释放／动作结束后应用；设置采样桥保留 |
| controller.input | deadzone=8000，范围1000..24000 |
| controller.movement | lead_tiles=12，范围6..32地图格 |
| controller.mouse | speed=900，范围100..3000桌面像素／秒，右摇杆为三分之一 |
| controller.feedback | rumble=true，既有模式切换震动 |
| gameplay.combat | charge_guard_on_hit=true、free_run=true、omnidirectional_guard=true、directional_dodge=true；dodge_distance=128，范围16..512世界单位 |
| gameplay.stamina | guard_mode="original"或"percent"；guard_percent=0.00；recovery_mode="guard"或"percent"；recovery_percent=0.00 |
| controller.bindings | default="game"，默认读取当前角色原游戏快捷绑定，不要求重新配置才能操作 |

百分比按最大体力计算，0..100.00、最多两位小数。文件12.50内部为1250，不通过浮点字符串往返。original保留原角色防御周期值，guard恢复量跟随防御实际消耗；0自定百分比可表达不扣或不恢复。原最低5点防御门、特殊穿防、伤害／拾取资格均保留。

## 技能绑定结构

默认game模式继续解析原游戏当前角色的HUD热键链，直接请求其selector与手侧；不注入这些键。RT层14槽顺序为A、B、X、Y、上、下、左、右、LB、RB、Back、Start、L3、R3。前12槽默认来源为Q、W、E、R、T、Y、U、I、O、A、S、D，L3／R3默认留空，保持迁移前操作。

自定义表为controller.bindings.daojian.character_N.slot_M或waizhuan版本。N是PlayerInitSelector（Player+0x348），不是对象kind+0x67，也不是原始内存地址或擅自命名的人物类别；两作PlayerInit原始指令均确认该字段。已见selector有4、30、40，外传另有223、1；人物名称映射仍需实际数据，不猜名称。M为1..14。

表内mode="skill"指定真实selector，hand="left"或"right"；mode="game"恢复原游戏来源。selector必须属于当前版本当前角色并由原业务资格核对；不保存最终Method。新绑定API把三个字段一起编辑、一次原子写盘。按版本／角色／槽位隔离测试、角色切换回原绑定及左右手转换回放通过；自定义绑定尚未单独完成实机验收。

## 保存与安全应用接口

RuntimeConfig_SetInt／SetText／SetBinding先生成完整候选、检查类型范围与重复定义，核对加载后的文件是否被外部修改，再以同目录临时文件、完整写入、FlushFileBuffers、MoveFileExW替换保存。失败不替换有效文件或内存设置；缺失TOML才生成默认，坏TOML不静默重建。注释和未修改项保留，新输出统一UTF-8无BOM＋CRLF。

接口只用于游戏线程内模块；当前不导出为跨DLLSDK，也不实现后台文件监视。手改TOML后重启游戏即可，游戏内设置窗口调用保存／应用接口。

| 应用方式 | 设置 |
|---|---|
| 安全输入边界 | 死区、鼠标速度、震动、名称、拾取、战斗消耗／恢复、技能绑定等普通参数；HUD居中／辅助层级在稳定绘制帧接收 |
| 当前动作结束且输入释放后 | 前探、方向闪避／距离、世界按键、菜单AB、Controller世界启停；不得半程改变运动 |
| 保存后重启 | 宽屏安装、逻辑高度、比例、字体；HUD布局和辅助层级已热应用，Controller世界启停在安全点应用 |

没有保存变化时配置只做状态快速检查，不再遍历描述表或额外解析玩家。外层帧提交普通参数后，Controller按快照generation同步Guard，不能遗漏外层已经提交的变化。QOL基础桥启动时一次安装，业务开关不重装Hook；掉落时间记录不因设置修改清空。

## 静态SDL与设备映射

固定完整源码thirdparty/SDL-release-3.4.16，以官方SDL3::SDL3-static目标和真实头文件链接，同一32位MinGW工具链。无动态函数表、LoadLibrary(SDL3.dll)、旧ZIP提取或手工XInput后备；SDL内部XInput／WGI／HIDAPI／RawInput／DirectInput后端由SDL管理。

关闭Audio、GPU、Render、Camera、Dialog、Tray及OpenGL／OpenGLES／Vulkan。保留Joystick、HIDAPI、Haptic、Sensor、Power和公共线程／事件／文件设施。上游DirectInput头文件检查受SDL_DIRECTX控制，后者依赖VIDEO/AUDIO；为保留DirectInput设备支持，库编译保留Windows Video公共代码。实际只初始化SDL_INIT_GAMEPAD，测试确认VIDEO／AUDIO没有初始化，不接管游戏绘制。

映射文件从ASI旁明确路径加载，Windows宽路径转换UTF-8，位于首次枚举／打开设备之前。无文件、损坏内容继续内置映射；有效Windows覆盖映射和中文目录已通过虚拟设备实际采样。Shutdown只退出自己的GAMEPAD引用，不调用全局SDL_Quit；多使用者引用保留测试通过。生产与游戏同寿命，未承诺运行中热卸载所有模块；线程停止／SDL关闭接口不能在Loader锁内调用。

## 性能与当前构建诊断

性能分析需区分原游戏输入间隔与插件各段耗时；缺少帧时间时不能认定UPX、SDL或目标遍历是唯一原因。

日志只开一次句柄，64KiB有界队列、低优先级后台批量写盘，普通游戏帧不等待磁盘。启动和场景收尾可显式Flush。后台日志已有并发完整性/顺序边界/CRLF离线验证；队列丢失计数进入性能摘要，不能声称崩溃／满盘时日志绝无丢失。

每5秒记录一次固定聚合计时：原版输入刷新、SDL采样、目标遍历、手柄业务、受击包装／原生受击、自动拾取；同时记录输入间隔及日志队列／写入／丢失。一次目标遍历只读两次时钟，不在每个敌人循环内逐条测量或写日志。各项可嵌套，不能简单相加；受击包装包含原生受击，输入间隔包含原逻辑／渲染／等待，不是纯插件耗时或精确FPS。

性能对照使用相同角色、地图、敌人数量和TOML，并保留完整聚合日志。日志首行和构建报告包含当前源码与构建输入内容摘要，本次只记录离线/加载结果及实机待验收。历史性能改善反馈不扩大为新产物、全部设备或设置，各阶段数据仅见《版本与更新记录.md》。

## Guard安全确认

生产采样桥调用Guard_SyncSettings，原位置仍在SDL采样后、INPUT_SAMPLED事件之前。只有配置候选存在时才查询当前有效玩家并判断按键/扳机释放、无ActiveRuntime、实际状态不为原版闪避17；原版和新方向闪避都被识别。旧dash.active不作为设置忙碌门，避免切图、换角色或中断留下的记录锁死应用。

Guard_ApplySettings返回是否全部接收。普通防御/体力字段保持原帧边界应用；确有方向/距离变化才查询实际角色，闪避中返回false并保留旧运动参数。即使其它调用者提前提交快照，也不会半程改位移。调用方只在返回true时更新applied_generation，拒收时下帧继续确认。没有候选、代数未变的普通帧只读内存，不增加磁盘I/O、重复应用或持续玩家解析。

当前闪避开始→保存新参数→当前动作用旧参数→动作结束→自动应用→下次动作用新参数。没有要求再次保存或重启。运动参数只在角色安全状态接收；旧对象不被补写或继续操控。

## 构建与验证边界

发行和完整版使用同次优化编译，完整版保留调试信息，发行副本剥离符号；比较所有非调试运行段。新增Guard热应用已有真实TOML与双游戏宿主验证，仍待实机。手改文件后重启只验证启动读取，不等于验证运行中保存/安全应用。游戏内设置窗口已实现并通过离线回放，仍待实机。

[controller.combat] single_trigger_ultimate默认false（双扳机必杀）、combo_switch_input默认face，可改dpad；旧模式固定十字切连招。RuntimeConfig_SetText接受描述表枚举名并复用SetInt的原子保存/帧应用链，未知枚举名拒绝；细则见《手柄双扳机动作菜单与交互响应说明.md》。

B技能预览扩散速度由[controller.skill_aim].expand_time_ms调整：默认1000毫秒，100～10000，越小越快。原技能最远距离不改，本次按B固定时长，保存后下次预览读取新值。源码及双发布TOML自动同步新键并保留已有设置；操作与边界见《手柄跳跃与落点预览说明.md》。

设置后端已接通RuntimeConfig_SaveBatch：普通选项与多角色槽位候选全部验证后一次原子保存，重复字段／重复槽／任一无效值／外部文件变更均拒绝整批，不部分写入。RuntimeConfig_Saved及GetSavedBinding提供已保存值；Current及GetBinding提供生效值，FRAME／IDLE／RESTART仍走既有边界。生产窗口已接通，说明键Y；仅世界操作和技能快捷改绑，菜单支持AB交换；离线回放不等于实机验收。
