============================================================
自动构建分发版使用说明与常见问题
============================================================

本文件可直接使用 Windows 记事本打开。
项目主页：https://github.com/Kanadeforever/EDSlash

本文面向下载 EDSlash-dev-auto.zip 的玩家，说明安装、更新、设置和故障排查。适用于《刀剑封
  魔录》本体与《刀剑封魔录外传：上古传说》的 Windows 版。当前为开发版，部分功能和设备组
  合仍需实机验证。

============================================================
一、下载与安装
============================================================

1. 在 dev-auto 开发版下载页：
https://github.com/Kanadeforever/EDSlash/releases/tag/dev-auto
 的附件区下载 EDSlash-dev-auto.zip。不要把 GitHub 自动提供的 Source code 压缩包当成可直
  接安装的插件包。
2. 完全退出游戏，打开实际游戏主程序所在目录。Steam 用户可以从游戏的“管理 → 浏览本地文件”
  进入，再确认游戏主程序的位置。
3. 备份存档、已有插件配置，以及将要替换的同名文件。原有 dsound.dll 可能属于其它模组；如
  有同名文件，先确认用途，不能直接覆盖后假设其它模组仍能工作。
4. 如果以前安装过 dgVoodoo2，或者是为Steam版《上古传说》安装本模组，先按下一节清理旧文件；
  同时删除旧的 EDSlash 插件。
5. 将压缩包中的全部内容解压到游戏主程序所在目录，保留目录结构。不要多套一层
  EDSlash-dev-auto 文件夹，也不要把 plugins 内的文件全部移到根目录。
6. 按平常方式启动游戏。Steam 版继续通过 Steam 启动。进入游戏场景后检查画面、键盘鼠标和手
  柄操作，再调整设置。
7. Linux/SteamDeck 用户，需要在游戏的“管理 → 通用 → 启动选项”里填入以下内容：
  HOST_LC_ALL=zh_CN.UTF-8 WINEDLLOVERRIDES="ddraw,dinput8=n,b" %command%
  注意：Steam版需要将Proton设置为9以上，并且在不安装解码器的情况下无法播放视频。

安装后的主要文件如下；其它随包文件也应保留：

游戏主程序所在目录\
├─ 游戏原有文件
├─ dsound.dll                 ASI 加载器
├─ ddraw.dll                   cnc-ddraw 显示兼容层
├─ ddraw.ini                   cnc-ddraw 配置
├─ cnc-ddraw config.exe        cnc-ddraw 显示配置工具
├─ plugins\
│  ├─ EDSlash.asi              EDSlash插件本体
│  └─ EDSlash.toml             EDSlash插件配置文件
├─ Shaders\                    cnc-ddraw 着色器及内嵌原始压缩包
└─ Third_Party_Licenses\       第三方声明与许可

  包内已附带 cnc-ddraw 7.1 和 Ultimate ASI Loader 9.0 的 32 位发行件，无需再下载另一份
  加载器，也不需要单独安装 SDL3.dll。游戏是 32 位程序，即使 Windows 是 64 位，也不能换成
  64 位加载器。

============================================================
二、安装前清理 dgVoodoo2
============================================================

当前分发包使用 cnc-ddraw。若游戏目录曾安装 dgVoodoo2，应先退出游戏，备份并删除下列由
  dgVoodoo2 安装的文件；没有的文件直接跳过：

DDraw.dll
  删除旧 dgVoodoo2 的 DirectDraw 包装器，随后由本包的 ddraw.dll 替换

D3DImm.dll
  删除旧 dgVoodoo2 的 Direct3D 包装器

D3D8.dll
  删除旧 dgVoodoo2 的 Direct3D 8 包装器

D3D9.dll
  删除旧 dgVoodoo2 的 Direct3D 9 包装器

dgVoodoo.conf
  删除旧 dgVoodoo2 配置

dgVoodooCpl.exe
  删除旧 dgVoodoo2 配置工具（如曾复制到游戏目录）

顺序是：清理旧 dgVoodoo2 → 解压当前分发包 → 保留新包的 ddraw.dll。 Windows 文件名通常不
  区分大小写，DDraw.dll 和 ddraw.dll 是同一个文件名；安装完本包后再照着上表删除，会把新
  的cnc-ddraw 一并删掉。

只处理游戏目录中确认属于旧 dgVoodoo2 的文件，不删除 Windows 系统目录中的 DLL，也不按扩展
  名批量删除游戏文件。如果同名 DLL 来自其它模组，应先确认来源。若另外安装过 dgVoodoo2 的
   Glide 包装器，也应单独核对来源后停用，不能仅凭名字删除原游戏依赖。

dgVoodoo2 的组件与配置机制可查阅作者官方说明：
https://dege.freeweb.hu/dgVoodoo2/ReadmeGeneral/
。本节是切换到当前 EDSlash 分发包的清理流程，并非对所有游戏的通用卸载要求。

============================================================
三、日常设置
============================================================

- 插件功能、手柄键位和宽屏设置：进入游戏场景后，按主键盘数字 1 左侧的物理反引号键打开模
  组设置；手柄可先按住 LT＋RT，再新按 Back。按界面说明修改并保存，键位显示可用于查看当前
  绑定，该入口在游戏的设置菜单内也有新增选项可进入。
- 输出窗口、缩放和显示后端：退出游戏后运行同目录的 cnc-ddraw config.exe。这些设置属于
  cnc-ddraw，与插件配置分开保存。
- 手工编辑插件配置：退出游戏后编辑 plugins\EDSlash.toml，保留 TOML 的引号、节名与键名。
- 宽屏与字体：第一次使用建议保持逻辑高度 480 和比例 auto。逻辑高度不是最终输出分辨率，调
  大可能使人物变小并增加负担。宽屏、逻辑高度、比例及字体 DPI 设置需重新启动游戏生效。
- 手柄连接：连接后先松开摇杆和按键，再开始操作。若同时运行手柄映射软件，应检查是否产生重
  复输入。

自定义技能配置保存在插件旁的 EDSlash.SkillContols.toml，文件名中的 Contols 是当前程序使
  用的实际拼写。默认状态不创建该文件；没有该文件不代表安装失败。详细设置见统一配置与模组
  设置说明（项目主页的文档区），操作说明见手柄战斗与动作说明（项目主页的文档区）和手柄菜
  单与物品界面说明（项目主页的文档区）。

============================================================
四、更新、回退与卸载
============================================================

【更新】

1. 退出游戏，备份当前可用的插件、显示组件和配置。
2. 保存 plugins\EDSlash.toml、已有的 plugins\EDSlash.SkillContols.toml，以及自定义的
  ddraw.ini。新版 ZIP 中的主配置是默认值，直接覆盖会丢失个人设置。
3. 用新版文件更新程序和配套文件。需要保留设置时，先把新版默认配置解压到临时目录，与旧配
  置对照合并新增项；不要把两份完整 TOML 简单拼接，否则可能出现重复项目。
4. 启动游戏检查。若出现问题，退出后恢复备份的同一套程序与配置，并保留故障日志供排查。

dev-auto 下载页会随 main 的成功构建更新，不是固定不变的历史版本。需要回退时，应自行保留
  已验证可用的 ZIP 和个人配置备份。

【卸载】

只停用 EDSlash 时，把 plugins\EDSlash.asi 移到游戏目录之外；配置可以保留。若要完整撤销本
  次安装，再根据安装前备份恢复显示组件和加载器。只有确认没有其它 ASI 插件依赖时，才移除
  本包的 dsound.dll。ddraw.dll、ddraw.ini、配置工具、Shaders 与许可目录也应按来源逐项处
  理，不删除原游戏文件和存档。

============================================================
五、常见问题与解决手段
============================================================

【解压后插件没有效果】
解决手段：确认 dsound.dll 与实际游戏主程序同目录，plugins\EDSlash.asi 没有多套一层目录
  ；检查是否被安全软件隔离，以及是否仍加载旧独立插件。

【启动黑屏、闪退或显示初始化失败】
解决手段：先检查 dgVoodoo2 是否按第二节清理，再确认新包的 ddraw.dll 已安装。备份
  ddraw.ini 后用包内默认配置复测；必要时通过 cnc-ddraw 配置工具逐一切换可用显示后端，每
  次退出游戏后再修改。若仍失败，收集日志，不把某个后端当作所有设备的固定答案。

【安装后仍看到 dgVoodoo 水印】
解决手段：检查实际启动的游戏目录是否与清理目录一致，并核对 ddraw.dll 来源；可能仍在使用
  旧包装器或另一份游戏安装。

【误删了 ddraw.dll】
解决手段：从当前分发 ZIP 重新解压 ddraw.dll 到游戏主程序旁。这时需要的是 cnc-ddraw 文件
  ，不是重新安装 dgVoodoo2。

【标题、主菜单或动画仍为 4:3】
解决手段：当前设计保留这些原版流程；进入实际游戏世界后再检查宽屏效果。

【人物变小、画面范围过大或变卡】
解决手段：将插件逻辑高度恢复为 480，再调整 cnc-ddraw 输出缩放。不要为提高最终显示分辨率
  而盲目提高逻辑高度。

【设置保存后没有立即生效】
解决手段：显示和字体相关项需重启；部分手柄设置需松开输入并等当前动作结束。确认修改的是
  plugins 中的配置，而非旧 INI 或另一份游戏目录的文件。

【无法打开模组设置】
解决手段：进入已载入场景后尝试物理反引号键；手柄先按住两个扳机，再新按 Back。先核对插件
  是否加载，最新设置界面的全部设备时序仍需实机复测。

【手柄无反应、重复操作或自行移动】
解决手段：确认系统能识别手柄、插件手柄功能已开启；松开所有输入后重试。检查 Steam Input和
  其它映射软件是否重复映射，逐项停用对照。摇杆漂移可适当增大死区。

【更新后配置报错】
解决手段：备份出错文件，检查重复键、缺失引号和错误数值。可换用本包默认 EDSlash.toml 验证
  ，再逐项恢复个人设置；插件不会主动覆盖损坏配置。

【提示游戏版本未知或不支持】
解决手段：当前按本体 1.05、外传 2.01 的 Steam／非 Steam 准确 EXE 维护。版本号相同但修改
  过的 EXE 不保证兼容；提供实际 EXE 身份与日志，不强行套用地址。

【没有 EDSlash.log】
解决手段：日志位于 ASI 旁，即通常是 plugins\EDSlash.log。检查 [logging] 下 enabled =
  true、目录写入权限及插件是否加载；日志不存在本身不能证明具体故障原因。

【下载页没有更新】
解决手段：自动发布只在 main 的构建与验证成功后执行。查看对应 Actions 记录；其它分支的手
  动构建仅提供附件，不覆盖公开开发版。

【Actions 附件不是直接安装包】
解决手段：下载附件后若得到外层压缩包，先解出其中的 EDSlash-dev-auto.zip，再按第一节安装
  内部发行包。附件保留期当前为 14 天。

============================================================
六、反馈问题
============================================================

1. 在 plugins\EDSlash.toml 中确认 [logging] 的 enabled = true。
2. 重新启动游戏，复现问题后退出，保存 plugins\EDSlash.log；已有日志会追加，反馈时说明本
  次复现时间。
3. 记录游戏是本体还是外传、Steam 还是非 Steam、Windows 版本、手柄型号、cnc-ddraw 显示后
  端，以及问题出现的地图、界面和操作步骤。
4. 附上插件“关于”页中的构建编号、相关配置与完整日志，在 GitHub Issues：
https://github.com/Kanadeforever/EDSlash/issues
 提交。说明使用默认配置能否复现，以及上一份可用包的情况。

自动构建成功说明构建和离线检查完成，不能替代当前游戏版本、设备与场景的实机测试。已知问题
  与验收范围见项目说明（项目主页的文档区）和手柄实机验证说明（项目主页的文档区）。
