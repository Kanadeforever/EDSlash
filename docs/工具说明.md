# 工具说明

## 1. `source\BladeSwordQOL\tools\verify_build.py`

统一构建与源码防回归验证器，只使用 Python 3 标准库，不联网、不改游戏文件。当前还会锁住 ModuleRegistry 故障隔离、Hook 声明回滚、AspectRatio 8 像素统一求值、layer1d、0x0B/0x0E 原版按压动画 root 校正以及外传 Steam 红线，防止后续手柄/QoL 开发把这些稳定资产改丢。

## 2. `source\BladeSwordQOL\tools\verify_compatibility.py`

统一 EXE 兼容检查入口。先按 PE 头识别 Profile，再分派到：

```text
source\BladeSwordQOL\tools\compat\compat_daojian.py
source\BladeSwordQOL\tools\compat\compat_waizhuan.py
```

两个子验证器继承此前 DisplayFix 的成熟签名检查，只读目标 EXE。

## 3. 永久字体工具

保留历史稳定工具：

```text
source\BladeSwordQOL\tools\font_fix\DaoJian\apply_dpi_font_fix.py
source\BladeSwordQOL\tools\font_fix\DaoJian\apply_fix.bat
source\BladeSwordQOL\tools\font_fix\WaiZhuan\apply_dpi_font_fix.py
source\BladeSwordQOL\tools\font_fix\WaiZhuan\apply_fix.bat
```

一般用户只需要 ASI 的 `[Font] FixDPI=1`；永久脚本仅用于特殊离线固化场景。

## 4. 维护规则

工具升级时包内只保留最新/最稳定版。新增工具必须同步本文件与 `完整接档说明.md`；所有说明文档仍只允许位于 `docs\`。
