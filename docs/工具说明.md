# 工具说明

## 1. `source\tools\verify_build.py`

统一构建与源码防回归验证器，只使用 Python 3 标准库，不联网、不改游戏文件。当前还会锁住 ModuleRegistry 故障隔离、Hook 声明回滚、AspectRatio 8 像素统一求值、layer1d、0x0B/0x0E 原版按压动画 root 校正以及外传 Steam 红线，防止后续手柄/QoL 开发把这些稳定资产改丢。

## 2. `source\tools\verify_compatibility.py`

统一 EXE 兼容检查入口。先按 PE 头识别 Profile，再分派到：

```text
source\tools\compat\compat_daojian.py
source\tools\compat\compat_waizhuan.py
```

两个子验证器继承此前 DisplayFix 的成熟签名检查，只读目标 EXE。

## 3. 永久字体工具

保留历史稳定工具：

```text
source\tools\font_fix\DaoJian\apply_dpi_font_fix.py
source\tools\font_fix\DaoJian\apply_fix.bat
source\tools\font_fix\WaiZhuan\apply_dpi_font_fix.py
source\tools\font_fix\WaiZhuan\apply_fix.bat
```

一般用户只需要 ASI 的 `[Font] FixDPI=1`；永久脚本仅用于特殊离线固化场景。

## 4. 维护规则

工具升级时包内只保留最新/最稳定版。新增工具必须同步本文件与 `完整接档说明.md`；项目说明放在 `docs\`；源码目录同级 readme.md 构建说明、tools 内工具说明按用户规则允许保留。

## 5. Controller 独立工具

工具位于 `source/tools/controller/`，不依赖外部项目和个人编译器路径文件。

| 文件 | 用途 | 依赖与输入 |
|---|---|---|
| `build_controller.py` | 构建、测试、校验、更新独立产物 | Python 3 标准库、32 位 MinGW GCC、随包 SDL ZIP；参考 EXE 仅用于可选双样本复核 |
| `generate_profiles.py` | 检查双版本 C 地址表与元数据一致 | 默认只检查；确认修改元数据后用 `--write` 重新生成 |
| `profiles.json` | 冻结两份非 Steam EXE 散列、地址、偏移、签名和 SDL 包散列 | 从参考基线只读提取，不以旧聊天地址替代 |
| `test_control.c` | 输入时间线、死区、层切换、走跑与八方向测试 | 由独立构建自动编译执行 |
| `test_load.c` | 实际加载 32 位 ASI 与 SDL，并检查 12 个公开导出 | 非游戏进程验证未知宿主安全返回，不初始化手柄设备 |
| `test_game.c` | 在 Win32 进程用同调用约定替身验证两版适配 | 覆盖调用对象、参数、A/X/Y 路由、菜单与快捷层；不是实机游戏 |

独立构建只更新自身 ASI 与 SDL，不覆盖已有 INI，不清空共享 release。详细调用方式见 `source/readme.md`。生成的 `release/手柄构建验证.json` 会明确区分双样本静态复核与待实机验收。
