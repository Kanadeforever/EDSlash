## 产物校验

verify_build.py解析真实PE导出/导入/重定位与标准TOML；runtime_sections/verify_variants比较非调试段RVA/虚拟大小/字节，verify_debug_info检查debug信息与发行剥离。文件内名称不代替实际GetProcAddress，工具不能证明Hook语义或实机。

## EXE兼容复核

统一 EXE 兼容检查入口。先按 PE 头识别 Profile，再分派到：

```text
source\tools\compat\compat_daojian.py
source\tools\compat\compat_waizhuan.py
```

子验证器只读 EXE，核对 DisplayFix 内容签名、调用关系、vtable 与 UI 结构；保留的历史结构不代表当前 ASI 安装对应旧 Hook。统一入口只分派 EXE；Steam ComeOn.dll 要直接调用 tools/compat/compat_waizhuan.py。QOL 三入口由 QOLModule 在运行时核对，不由此工具完整验证。

## 永久字体工具

工具路径：

```text
source\tools\font_fix\DaoJian\apply_dpi_font_fix.py
source\tools\font_fix\DaoJian\apply_fix.bat
source\tools\font_fix\WaiZhuan\apply_dpi_font_fix.py
source\tools\font_fix\WaiZhuan\apply_fix.bat
```

一般运行用 ASI 的 `font.fix_dpi=true`。永久脚本验证 PE 与唯一上下文，只修改同目录 *_DPI_FontFix.exe 副本的 6 字节范围并重读比对，不覆盖输入 EXE；已修复输入不重复生成。同名输出副本可能被覆盖，不可把工具输出置于只读参考目录。

## 原生动作只读研究

`source/tools/controller/trace_native_actions.py` 只读两份非 Steam 基线，验证冻结 SHA-256 后使用 pefile 与 Capstone 解码原生技能解析、执行、转向、历史回写、输入分发等已登记函数范围与基本块，并验证历史门初始值及各 6 处写入。依赖仅用于研究工具，正式构建仍使用 Python 标准库，不自动安装依赖。

从项目根运行：

```powershell
python source/tools/controller/trace_native_actions.py --baselines "参考资料/刀剑封魔录系列反编译资料库_v0.31/基线程序" --output "docs/手柄原生动作拆分证据.txt"
```

只有两版全部校验和完整解码成功后才写输出。工具拒绝把输出写入只读参考资料或基线目录，不运行游戏、不修改 EXE、不安装 Hook。解码从已确认函数起点进行，不从任意地址猜指令边界。结果说明局部静态控制流，不证明实机触发频率或完整功能可用。

## 宿主与虚拟设备

CMake登记输入、连续方向、双游戏战斗、菜单及调查回放、Guard真实TOML应用、QOL提示、Runtime故障、公共帧、后台日志、配置、静态SDL与ASI加载。Guard集成执行生产同步与运动，其他替身按自身覆盖限定；结果不冒充游戏/真实设备。

## 菜单回放工具

source/tools/controller/test_menu.c由CMake登记为test_menu，复用test_game.c的32位fixture，链接真实Control/Menu/Game。覆盖原菜单、日志左右翻屏/分类、读档上下跨页、技能连招及背包/仓库50格、原BC详情门、A原物品操作、B取消/X切已显示页/Y切区、45槽与七处局部调用共52处失败回滚、Draw兼容和输入隔离。运行于自有宿主，不启动/注入游戏，不改个人配置。

菜单地址纳入profiles.json和生成头文件；verify_profiles.py读取成对样本检查45个焦点槽及业务槽/光标/世界悬停/技能调用，函数头照原签名核对。整个虚表前三项不作运行时签名，因为Draw属于显示模块可合法包装。

## 技能与日志只读研究工具

`source/tools/controller/trace_menu_pages.py --output docs/手柄技能日志界面原始证据.txt`读取两份冻结散列的非SteamEXE，以标准库PE读取及Capstone解码虚表、技能主操作、日志编排、技能base更新调用、连招命中和绘制六列布局。Capstone仅研究时需要，构建不自动安装。输出参数必填，拒绝参考资料目录；输出UTF-8无BOM与CRLF，保留机器字节。工具不启动/注入游戏、不读写存档。地址和栈参数还由双样本槽/CALL检查和32位宿主回放补证，静态证据不是实机验收。

加`--learning --output docs/手柄必杀自动学习原始证据.txt`只导出原主操作、学习函数、同组第四记录自动补入、已学资格和必杀说明分支；先解码两作原学习CALL，核对480DA0／48FBD0目标。不同研究范围单独存证，不覆盖既有原始TXT。test_menu另覆盖原删除后的同帧焦点补位、末项回退、空清单、原拒绝和按住不连删，必杀自动学习没有伪造宿主验收。

加`--grid --output docs/手柄背包储物箱原始证据.txt`只读导出两作背包/储物箱原详情、BC物理路由门、格号和主/辅助操作、24像素10列命中及持有物品交换。--grid与--learning不能同时使用，输出仍拒绝参考资料，正式构建不依赖Capstone。

加`--regions --output docs/手柄多区域与持有图样原始证据.txt`读取六区域扩展业务、根工厂登记ID及软件图样原持有分支减半尺寸。三个研究范围互斥，旧证据不覆盖；本体/外传新虚表和商店/镶嵌私有坐标调用由verify_profiles.py解码复核。test_menu新增辅助页不在普通链/属性13=0、六区域循环、隐藏过滤、原特殊槽业务、商店模式和确认、空存档尾页及外传标题图样差异，所有非标题场景同时回放两作。

## 构建配置同步

sync_config.py不另建构建入口，唯一构建说明仍为source/readme.md。构建器读取生产生成模板和全部目标配置，解析成功后只补模板缺失键：存在段在段末插入，不重复声明；缺失段在文件末追加，复制新键的说明注释。旧角色绑定和其它已有值通过全叶子快照逐一复核；合并后标准tomllib再解析并核对模板键完整。无需补键时保持原字节，补键时UTF-8无BOM与CRLF；同目录临时文件原子替换，外部改动检测失败则拒绝写入。语法损坏、重复定义或无法安全扩展的表不会覆盖；此工具不替代运行时的类型/范围/未知键检查。

发行与debug每次正式构建都同步，--upx生成件配套同步；未重压时旧UPX的ASI和TOML都不改。checks-only运行回归但不写发布配置。Python测试用source/.build临时目录，验证真实模板max_distance补入、已有free_run自定义值/角色绑定/注释保留、幂等、缺文件生成、语法失败和并发修改保护。构建报告记录补入键，不复制到任何游戏安装目录。

test_inspect.c真实链接Inspect/Game，使用局部地图格、句柄与原调用包装回放，检查扇区/静态/去重/原悬停；不运行真实脚本。菜单工具增加原删除对话与Cursor绘制两个分支，使用自有对象，不读取或删除个人游戏存档。

trace_interaction_ui.py --output <证据路径>只读四份冻结EXE，验证SHA并由Capstone从真实入口导出静态返回链/NPC对话。输出拒绝参考资料目录；正式构建不依赖Capstone。当前新增证据为《手柄静态资格与对话原始证据.txt》。

trace_interaction_ui.py现可导出原鼠标按下写2C4及单句Tick/Space额外滚动，证据另存《手柄对白滚动与鼠标配对原始证据.txt》，不改旧TXT。

## 维护

自有工具在source/tools，模块工具说明与本文/接档同步，包内保留最新稳定实现。不恢复已删除构建/检查别名，不向只读参考目录输出，不自动安装研究依赖，不依赖个人编译器地址文件。构建说明唯一source/readme.md。

Controller研究导出统一从profiles.json的game_id/edition读取四个准确样本，不再用zip把四表截成两表。trace_menu_pages.py --regions可生成《手柄四版本多区域原始证据.txt》，记录四份SHA与原业务。旧原始证据保留其当时样本范围；正式构建不依赖Capstone。test_game新增原地形阻挡前探、紧邻墙不发绕路和通畅目标恢复；test_menu新增全部物品页确认焦点恢复、镶嵌双区、R3及过期依附页之后世界A。
