## 关键限制与未改的实现问题

1. verify_build.py 不检查 QOL 必需字段和参数范围，也不检查文档、源码、Hook、事件或 GUI 回归。导出检查采用 Export Directory 存在及文件内 InitializeASI 名称，并未完整解析导出表。已据此改工具／构建说明；未改验证器。
2. DisplayFix 有效句柄初始化后返回 1，即使内部部分功能失败；Registry 状态不证明全部显示功能成功。DisplayFix Claim 成功后也没有统一在后端各 patch 失败时释放 owner 的事务。文档按实际边界写，不宣称所有模块失败都恢复原样。
3. Runtime 写后缓存／保护失败返回 2，X86Detour_Install 仍保留安装并返回成功；资源不会因该状态直接释放，但返回成功也不是附加处理均成功的保证。
4. Controller Main.patch 在写入后没有核对 FlushInstructionCache／恢复保护的返回值。Guard 安装失败时对先前入口的恢复结果未逐项确认；这些路径不受 Runtime 28 项故障测试覆盖。仅记录风险，不扩大为当前已修复或全部安全回滚，本轮不改代码。
5. UI_DRAW_END 在原版 Draw 返回后广播，后面仍可能补画未被 HUD wrapper 消费的 GUI；不能作为全部 UI 呈现结束的总门。
6. 本体 Steam 路径启用延迟 JMM；外传初始化检测 ComeOn.dll 后仍置 g_steam_environment=FALSE，延迟路径休眠。历史外传日志不能证明当前仍启用。
7. 普通手柄战斗已使用独立目标／历史，但 Game.inspect_action 的静态交互仍读取原鼠标候选 +0x40；完整 GUI／出口业务没有全部完成，不能写成所有手柄业务都已脱离鼠标候选。
8. 旧背包 Save/Load 固定块、Type 40 任务语义和 Probe 用户通过均作为合并前-alt 旧记录，不作为本轮游戏事实重新验证。背包分页／存档尾部扩容尚无实现。
