# 手柄原版设置操控说明

## 页面与操作

接入的是原游戏设置页JM AA，标题菜单和游戏内系统菜单共用该页；插件自有TOML设置窗口仍使用其独立入口。上下或左摇杆上下按实际控件几何移动焦点，左右或左摇杆左右调整当前滑块；两组选项左右移动到同组相邻项并调用原选择业务。A确认选项或返回按钮，滑块上的A不模拟点击位置。B与START菜单返回请求沿原SettingsClose关闭；不另写配置。LB/RB、X、Y在原设置页没有额外用途。

三个滑块使用原100上限和当前值，左右一步1，原setter负责夹紧到0..100及滑块位置更新。方向首按立即处理，350毫秒后以110毫秒间隔重复，持续两秒后缩短至35毫秒；选择不同方向重新开始计时。设置页全部使用既有软件鼠标指针作为焦点标记，不把滑块或按钮画成物品格子框。页面打开/来源切换/关闭后均保留旧输入释放屏障。

## 原生业务和地址边界

根虚表本体529FCC、外传5532E0；Tick 4A5BE0/4B83B0、Show 4A6030/4B8800、hover 4A6FA0/4B98D0、主释放4A5B50/4B8320、关闭4A5C40/4B8410、实时应用4A5A70/4B8240、滑块setter 4C9560/4DE090。Steam和非Steam逐份按完整EXE身份、构造器虚表、虚表槽、Show的三个滑块CALL和主按钮/Esc到close的CALL复核，不能仅凭两份地址相似认为另一版正确。地址统一登记profiles.json并生成ProfileData.h，新增函数同样经过运行时签名检查。

八个子控件ID为AB..B2：AB/AC/AD滑块，AE/AF组A，B0/B1组B，B2返回。子对象从本页当前子链读取，只接受显示、有尺寸且父页正确的对象，不持久保存子指针；隐藏项目不参与导航。根A8只投影当前按钮，不改选项本身的选中精灵。滑块设置完暂时清空A8调用原MouseMove应用后半段，避免虚构坐标再次拖动滑块，之后重新投影焦点。原保存、声音/显示即时更新、标题或游戏内返回由原游戏负责。

Menu只包装该页Tick/Show/hover三个槽，业务入口仍调用原函数；Draw和生命周期保存槽不改。安装前核对全部原槽，任一步写入失败撤回已装槽。物品页种类限定BAG..QUICK七个编号，设置等普通页不能索引库存区域数组、生成持有物品业务或快捷格焦点。

原设置页基础操控已获用户实机确认；连发加速为新增调整，仍待复测。

## 验证和后续

原指令见《手柄原版设置四版本原始证据.txt》，研究工具使用见source/tools/工具说明.md。两作宿主回放覆盖三个滑块、0/100边界、长按重复、两组选项、A/B返回、B优先同帧输入、无捕获对象的登记链入口、隐藏控件跳过、指针策略、世界输入隔离及安装失败回滚。静态和离线结果不替代实际滑块效果、文字位置、返回持久保存的实机验收。

实机需分别从标题和游戏内进入：调整三个滑块，切换两组选项，分别用A返回与B返回，重开检查原值；同时确认LB/RB无额外动作、关页后按键释放才能恢复世界操作。本体与外传、Steam与非Steam分别记录结果。新游戏角色/名称/难度页尚待接入，不能由设置页完成宣称新游戏流程已完成。角色变色与罕见启动异常调查状态继续保留，设置页接入不代表它们已修复。
