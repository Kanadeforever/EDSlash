# 手柄防御闪避与热切换说明

> 文档维护约定：本文按主题维护当前有效的技术正文，不再追加版本更迭、日期同步或发布补丁章节。版本变化、旧版散列、阶段测试与用户反馈统一记入[版本与更新记录](版本与更新记录.md)；技术结论变化时直接修订对应正文。

## 输入接管

真实物理键/鼠标新边沿与摇杆输入分别判定来源，稳定按住不误接管。交接先停止旧来源未提交请求，再保留已成功动作的原生历史和进度；不每次切层清掉全部战斗锁定。失焦/断线/场景变化等待释放，避免旧held泄漏。

BACK+START提供主动鼠标模式，普通手柄仍独立组织目标与动作。模式切换不代表完整原生GUI和鼠标焦点隔离都已实现。

## 防御与体力

LT调用原防御资格和opcode16/状态事件，保持原角色朝向，避免ON事件按鼠标点重定向。原Alt松开生产端需按来源处理，不能下一帧把手柄防御取消。全向格挡只接管当前有效防御玩家，保留原最低5点及特殊穿防。

受击扣费、实伤恢复和全程免费跑步按当前TOML设置，幅度以最大体力百分比计算，详见《手柄快捷施放与体力规则说明.md》。

## 方向闪避与安全应用

LT+左摇杆按投影方向启动状态17的新直线运动，回中才重触发；方向锁定，本次8逻辑更新完成，默认128世界单位。每8单位检查经过格和地形/占用，斜向检查两侧，障碍提前结束；原grid_commit与虚表+8位置setter保持占用/坐标一致。关闭新位移回原目标门与运动。

方向开关/距离不能半程改变；真实当前角色状态17阻止动作设置提交。Guard拒收时不消费generation，动作结束后重试确认。机制详见《闪避设置安全应用修复说明.md》。受击免疫是前半段0x66普通受击门，证据限制见《闪避无敌窗口与界面调研记录.md》。

## 双游戏接口

| 入口/字段 | 本体 | 外传 |
|---|---|---|
| 原生历史清理 | 0x475010 | 0x483890 |
| 防御状态 Getter | 0x42B310 | 0x4343E0 |
| 防御资格 | 0x41C9C0 | 0x424FA0 |
| 体力变更 helper | 0x424D70 | 0x42DA20 |
| 防御周期扣费 CALL | 0x42429D | 0x42CE4F |
| 奔跑周期扣费 CALL | 0x42424C | 0x42CDFF |
| 实际受击防御状态 CALL | 0x419FC5 | 0x422315 |
| Alt 松开状态 CALL | 0x474B49 | 0x4833C9 |
| 闪避启动 | 0x41B290 | 0x4237E0 |
| 闪避目标门六字节 | 0x41B301 | 0x423851 |
| 手柄状态安装后返回 | 0x41B338 | 0x423888 |
| 体力偏移 | +0x3AA | +0x3B6 |
| 生命偏移 | +0x3A2 | +0x3AE |

目标门原字节均为 85 FF 74 6A 57 56。裸钩子非手柄路径重放 test/条件跳转及两个压栈，手柄路径额外保存 EBX 并按四参数 thiscall 安装状态，再返回原版后续。不是把包含相对跳转的原字节直接复制到另一个地址。



外传真实受击基址0x422360，对应Getter CALL为0x4224D4；不能把同Getter的旧候选当真实受击入口。两作生命、体力与调用约定须分别核对。

## 验证范围

原交接与防御有分项实机确认；新热应用仍待实机。离线宿主验证不能代替复杂地形、原动画、所有攻击类型和设备。当前EDSlash.log统一记录来源/交接/防御诊断与聚合性能，不使用独立日志文件。
