# 构建与测试说明

> Controller 硬性要求（2026-09-27）：同一独立 ASI 同时支持非 Steam 本体 1.05 与外传 2.01，功能与验证必须两版成对完成；Steam 后置不代表外传后置。当前基础版已构建并完成两版静态及适配回放检查，本体与外传实机验收均待完成，完整操控设计仍有未实现项。

## 1. 一键构建

Windows 下运行 `source\build.bat`。`build.bat` 直接位于 `source\`，不允许再增加 `source\BladeSwordQOL\` 中间目录。构建脚本优先使用 PATH、`C:\Program Files\LLVM\bin`、Visual Studio 最新实例的 `VC\Tools\Llvm\x64\bin`，不会递归扫描 ARM64 LLVM。

包根长期固定为：

```text
docs\
source\
release\
```

源码工程直接位于 `source\src\`，工具位于 `source\tools\`，配置模板已迁入 `source\config\`，主构建、验证器和独立手柄构建器均已同步。BAT 固定 UTF-8 无 BOM + CRLF；所有有正文的 `REM` 与 `echo` 行末尾必须有两个半角空格；成功结束和所有失败分支都必须 `pause`，构建失败保留 `source\.build\Main\` 方便诊断。

## 2. 输出

```text
release\BladeSwordQOL.asi
release\BladeSwordQOL.ini
```

以上要求仅针对当前主插件目标：PE32/i386、DLL、非零入口、导出 `InitializeASI`、Import Directory=0；该目标只有 `source\src\Main.c` 拥有 `DllMain/InitializeASI`。

2026-09-27：Controller 基础版通过 `source\build_controller.bat` 独立构建，构建说明统一见 `source\readme.md`。主 `build.bat` 已改为保留 release 其它目标，只检查自己的 ASI/INI。Controller 已完成双基线静态复核、69 项输入规则检查与两版适配回放，但两作实机验收均待完成。详细范围见《手柄模块接档说明.md》，测试步骤见《手柄实机验证说明.md》。

## 3. 构建验证

```text
cd source
python tools\verify_build.py ..\release\BladeSwordQOL.asi
```

检查 PE 属性、release 内容、docs 位置和编码、Profile 身份、ModuleRegistry/HookManager/EventBus、模块故障隔离与 Hook 声明回滚、两个后端共享事件、AspectRatio 8 像素算法一致性、layer1d 防回归、0x0B/0x0E 原版按压动画 root 校正、外传 Steam 红线和统一 INI/log 文件名。

## 4. EXE 深度兼容验证

```text
cd source
python tools\verify_compatibility.py <ComeOn.exe> [更多 EXE...]
```

统一入口先识别 Profile，再调用成熟的本体/外传只读验证器。

## 5. v0.1-dev1 本体实机验收

## 5.1 从旧 DisplayFix 切换到统一版

实机测试统一版时，**不要同时加载旧 `DisplayFix.asi` 和新 `BladeSwordQOL.asi`**。两者会争用同一批已知 Hook，任何“双加载”结果都没有诊断价值。

测试目录应只放统一版：

```text
BladeSwordQOL.asi
BladeSwordQOL.ini
```

旧 `DisplayFix.asi / DisplayFix.ini` 请先移出 `scripts` 或 ASI 加载目录。统一版运行日志改为 `BladeSwordQOL.log`。

1. 日志首部应显示 `BladeSwordQOL v0.1-dev1` 与本体 Profile。
2. `BaseHeight=480 + AspectRatio=16:9` 应得到 `TargetWidth=856`。
3. 最右侧竖条应保持消失。
4. Strategy 进入/退出与标题返回正常。
5. 物品/装备/技能 GUI 位置、层级、鼠标和快捷键正常。
6. HUD 重叠区按钮正常。
7. 左侧装备面板打开后单独关闭物品主窗口，面板仍在 HUD 上方且可操作。
8. 0x0B/0x0E 顶部按钮和世界点击穿透不得回归。
9. **新增重点：**鼠标按下属性/物品两个顶部圆形按钮时，应恢复原版按压/点击动画；功能仍只能切换一次，不能因为原版路径恢复后与旧 fallback 叠加成双重反转。
10. 日志若原 picker 没选 HUD，应限量出现 `主HUD按钮按压root校正`；若原版本来就选对 HUD，不要求一定出现该日志。

- 非零入口；
