# Runtime焦点提示服务与格子界面说明

## 当前职责

安全原动态框绘制已从Controller提炼到source/src/Runtime/Focus.c，公开接口在Focus.h。Controller的Cursor.c只注册本帧焦点提供者并管理软件光标/持有图标；Menu.c和ActionMenu.c继续负责导航、焦点、确认取消和原业务。Runtime不依赖Controller头文件、g_profile、g_input或g_intent，不读取菜单对象或操作库存。

Runtime初始化共享服务早于ModuleRegistry，独立于Controller开关。没有提供者不绘制；原接口签名失配只停公共提示，不阻止其它模块初始化。服务自己消费既有UI_DRAW_END，不占DisplayFix Draw槽，不重画HUD或改世界输入。

## 模块接口

| 接口 | 行为 |
|---|---|
| RuntimeFocus_Initialize | 根据Runtime游戏身份校验原绘制接口并订阅共享UI绘制结束 |
| RuntimeFocus_Register | 用合法RuntimeModuleId注册提供者；同回调/数据幂等，冲突拒绝 |
| RuntimeFocus_Unregister | 注销该模块及其最近绘制标记；NONE/COUNT/非法值不操作 |
| RuntimeFocus_WasDrawn | 查询该模块是否在最近UI帧成功绘制，资源不可用可保留原反馈 |
| RuntimeFocus_Stage | 供异常记录器取得当前共享渲染阶段，绘制外返回NULL |

提供者签名为int(RuntimeFocusRequest*,void*)，每个UI绘制帧重新验证页面并返回矩形/优先级，0表示无有效焦点。Runtime不跨帧保存CJm/Slot/角色裸指针。注册/查询/注销在游戏线程调用，模块自行管理状态和提供者userdata生命周期；提供者注销自己后本次结果也被排除。

Runtime只画最高优先级的一项，同优先级按模块编号稳定选取；无效矩形不遮挡合法低优先级焦点。当前Controller物品页50、原物品确认/动作菜单100。未来MOD界面等其它模块可按自己真实输入所有权提供焦点，不以所有已打开窗口作为共同高亮。输入导航、原业务、物理接管和页面关闭都仍由提供者决定。

矩形使用原GUI逻辑坐标，不改HitRect/布局/鼠标位置。宽高4..128，使用64位减法检查溢出；关闭/隐藏/模态遮挡/来源变化时提供者返回0，绘制结果在下一UI帧清除。

## 原资源与四版本档案

FocusData.h由source/tools/generate_focus_profiles.py从同一profiles.json生成，共享六字段：HUD全局/虚表、SpriteDraw、RectDraw、FrameGetter、ImageGetter。同一游戏折叠Steam/非Steam行之前逐字段和签名证明相同，差异即拒绝生成，不借用偏移。生成/同步检查纳入正式构建。

Runtime使用GameProfile的PE游戏身份和四函数12字节签名作为共享绘制门；Controller自己的四份准确SHA和动作签名门继续保持，服务不代替它。当前四准确EXE源地址/签名、原调用链及清栈均静态核对，全项目audit额外读取实际Runtime生成表，防止共享表串用另一作地址。

| 原接口 | 本体 | 外传 |
|---|---|---|
| HUD全局／虚表 | 55BBB0／52A7D4 | 58D164／553B34 |
| 普通精灵绘制 | 4F4BE0 | 50BAC0 |
| 矩形裁取（不是缩放） | 4F4C10 | 50BAF0 |
| 动画帧getter | 4F4D60 | 50BC40 |
| 图像getter | 4F5CF0 | 50CD10 |

每帧读取当前HUD第5动态精灵，验证动画表/下标、22字节帧、资源管理器/登记对象、源图及目标缓冲区尺寸；不缓存旧地图资源对象。同尺寸原Draw，不同尺寸以原边缘片段拼接，每片限制源范围，中心透明不画。素材暂不可用时Controller保留旧箭头临时指示，不能变成无反馈页面。

原错误“十参数就是缩放”的解释已撤销，用户实机确认过安全源图方案；这次是服务迁移和格子提示扩展，仍待新实机，不把旧反馈扩大为迁移后全面验收。

## 已接入格子与操作

背包/仓库/购买50格、合成7槽、镶嵌12槽、护身石5槽、HUD十二快捷格、这些物品页的按钮区和原二级确认框，全部使用同一公共框。左右手动作菜单继续同框，右下收边已保留。物品空手不再用鼠标箭头提示；持有时保留原物品图标，原交换/堆叠/资格/数量/资金/属性规则继续原业务。

背包/仓库/购买虚拟格按原资源页坐标和24像素格生成26像素外框；快捷格保持已验收外框；特殊槽/按钮/确认项按真实控件边界贴合。持有图标使用原控件中心，框不提供点击或拿放函数。HUD A8隔离仍保持，不把快捷格伪装成主按钮。

X循环当前已打开物品区域，Y格子/按钮分区，B分级取消，Back道具箱原丢弃；LB/RB仅日志/招式有效。原物品模态框仍优先，返回后恢复原页和格号。字体、脚本、交易/库存与世界交互不由共享框改变。其它页的原生高亮/箭头当前保留，尚未实现的页面不假装已支持。

## 验证与接档

test_menu链接/包含真实Runtime服务及生产菜单，宿主原接口替身只提供自有帧/图像，逐片检查源范围。覆盖七区域/按钮/确认框矩形、持有中心、模块ID非法值、幂等/冲突、优先级、无效高优先级矩形、提供者自注销、物理接管、旧成功绘制标记清理和原A/B/交换/丢弃回归。

启动故障与异常文本测试继续保持；Crash.c通过共享Stage取Runtime绘制阶段，Runtime不反向调用Controller诊断。最新debug仍是同一优化链接件保留源码符号，实际GUI/设备/Steam环境按分项验收。
