# 手柄键位显示与实际路由核验

## 核验范围

直接核对当前Controller模块的Control.c、Game.c、Guard.c、Feedback.c、ActionMenu.c、Menu.c、Input.c与SettingsWindow.c的keymap_effect。以下是当前源码行为，不是另拟的按键方案，也不宣称本轮已经实机验证。滚轮视口和系统默认焦点已修复，构建日期已显示。键位图新增鼠标救援第五页；前四页的文字差异仍按本报告列出，尚未修改。

输入层优先级为：救援鼠标模式、普通原生菜单、已展开动作菜单、LT+RT、RT、LT、LB、RB、普通世界。普通菜单存在时不能套用世界组合键。世界七项改绑只作用于普通世界层；LT、RT、LB、RB组合不跟随它们改变。键位图读取设置草稿，实际动作读取已生效配置，两者在保存／安全应用前可有预期差异。

## 默认四状态的实际功能

下表基于默认世界按键、single_trigger_ultimate=false、combo_switch_input=face。双扳机面键列仅指技能菜单尚未展开。RT槽位显示具体角色已保存技能，未设置不发动作。

| 控件 | 一般世界 | 按住LT | 按住RT | 按住LT+RT |
|---|---|---|---|---|
| A | 调查／交互 | 选择第3套连招 | RT槽1 | 第1必杀准备／再按释放 |
| B | 按住落点预览，松开发动原第一快捷技能 | 选择第2套连招 | RT槽2 | 第2必杀准备／再按释放 |
| X | 当前左手动作，按住可续接 | 选择第4套连招 | RT槽3 | 第3必杀准备／再按释放 |
| Y | 当前右手技能或连招，按住可续接 | 选择第1套连招 | RT槽4 | 第4必杀准备／再按释放 |
| ↑ | 注入原C菜单热键 | 无效果 | RT槽5 | 无效果 |
| ↓ | 注入原V菜单热键 | 无效果 | RT槽6 | 无效果 |
| ← | 注入原N菜单热键 | 无效果 | RT槽7 | 无效果 |
| → | 注入原B菜单热键 | 无效果 | RT槽8 | 无效果 |
| LB | 回复物品组合层 | 无效果 | RT槽9 | 无效果 |
| RB | 投掷物品组合层 | 无效果 | RT槽10 | 无效果 |
| BACK | 默认无单键动作；与START切救援鼠标 | 无效果 | RT槽11 | 打开EDSlash设置，要求START未同时按住 |
| START | 延迟120毫秒请求系统菜单 | 无效果 | RT槽12 | 无单键动作 |
| L3 | 左杆移动时开始奔跑；回中停止，不是开关切换 | 无效果 | RT槽13 | 展开／切到左侧技能菜单 |
| R3 | 小地图Tab，要求世界与角色有效 | 无效果 | RT槽14 | 展开／切到右侧技能菜单 |
| 左杆方向 | 移动；普通攻击定向；B预览时选择落点方向 | 推动触发闪避，回中后可再次触发 | 移动与技能施放方向 | 菜单未展开不移动／闪避；展开后按导航模式使用 |
| 右杆方向 | 无世界功能 | 无效果 | 无效果 | 菜单未展开无导航；展开后按导航模式使用 |

LT本身是防御修饰键；RT本身进入快捷技能层，不展开动作菜单。原C/V/N/B分别由Game_Keyboard明确注入；本报告不凭键名猜各版本的菜单中文名称。动作均受原游戏资格、空套组、角色、物品数量和插件开关限制，显示某种功能不表示原游戏必定允许本帧发动。

## 配置分支与技能菜单

- combo_switch_input=dpad时，LT+↑／→／↓／←选择第1／2／3／4套，面键不再切套。
- single_trigger_ultimate=true时，单LT的A/B/X/Y改为第1/2/3/4必杀准备／再按释放；连招固定由LT+方向键选择。Feedback_Ultimate在两种输入模式下都先准备，再次新按同一键才请求释放。
- 空连招套组不可切换。必杀顺序沿角色原选择表和资格；A/B/X/Y对应第1/2/3/4项，不按图标或名字排序。
- 技能菜单始终只展开一侧。independent为左杆负责左侧、右杆负责右侧；left或right分别允许指定一根摇杆导航任一侧。另一杆不能抢焦点。
- 菜单已经展开时，ABXY不再准备或释放必杀，也不执行普通动作。L3/R3仍切侧；松任一扳机提交当前菜单选择；LT只维护防御，不再闪避。

## LB与RB组合

Game.shortcuts使用固定A、B、X、Y、←、→次序。LB加这六键分别调用回复物品快捷位1至6；RB加这六键分别请求投掷快捷位1至6。↑／↓没有这两层的快捷动作。它们是直接使用／投掷的组合层，源码没有按住LB或RB打开另一份选择菜单的逻辑。

## 普通菜单、插件设置与鼠标救援

普通原生菜单默认A确认、B返回，左杆或方向键导航；右杆没有通用菜单导航作用。swap_confirm_cancel只交换菜单A/B。LB/RB、X、Y、BACK等按当前页面另有分类、区域、套组或辅助功能，不能与世界四状态图混在同一个无条件说明中。

EDSlash设置使用LB/RB切主页面、方向键／左杆导航、START保存、BACK重置、Y查看说明（信息页与候选列表另有限制）；左右在键位图内翻状态。数值编辑方向步长与连发按当前描述表规则处理。

没有按住LT/RT、且未持有动作菜单时，BACK+START切救援鼠标。此时左杆移动鼠标，右杆以左杆三分之一速度微调；RT鼠标左键、LT鼠标右键。这个模式优先于四种世界状态，不能套用RT技能或LT防御解释。

## 当前显示差异

| 当前显示位置 | 当前文字／显示 | 源码核验结论 |
|---|---|---|
| 一般状态方向键 | 四键都写快捷物品 | 错，应按C/V/N/B原菜单热键显示 |
| 一般状态RT | 展开技能 | 错，进入快捷技能层；动作菜单由LT+RT+L3/R3展开 |
| 一般状态LB | 展开物品 | 错，是回复物品组合层，不打开菜单 |
| 一般状态RB | 展开投掷 | 错，是投掷组合层，不打开菜单 |
| LT状态左杆 | 防御方向 | 错，单LT推动左杆触发闪避；双扳机才禁止闪避 |
| 一般状态L3 | 奔跑切换 | 不准确，当前代码不是按一次开、再按一次关的切换 |
| LT+RT状态BACK | 无效果 | 错，实际打开EDSlash设置 |
| RT状态左杆 | 移动／落点方向 | 不准确，RT是移动／技能施放方向；B落点预览仅在一般世界层 |
| 一般状态B | 仅显示技能名／跳跃 | 名称可随角色变化，但遗漏按住预览、松开发动的规则 |
| 必杀面键 | 仅显示必杀名字 | 名称与位置有依据，但遗漏准备／再次新按释放的两步操作 |
| 双扳机摇杆与面键 | 不区分技能菜单是否展开 | 导航仅展开后有效；必杀面键仅未展开时有效，不能无条件并列 |
| 一般状态BACK与START | 分开显示无效果／系统菜单 | 单键解释基本对应，但漏掉BACK+START救援组合 |

14个RT物理按键与槽位的映射、默认LT面键切第3/2/4/1套、方向切第1/2/3/4套、L3/R3展开侧别、导航模式草稿显示，经逐项对照未发现映射顺序错误。未使用摇杆的无效果、未载入角色的不可用和空套组的无效果也有相应判断。
