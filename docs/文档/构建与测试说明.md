# 构建与测试说明

> 维护约定：本文直接维护当前有效的技术正文，不追加版本更迭或日期同步章节。阶段变化、发布身份及测试执行记录见[版本与更新记录](版本与更新记录.md)。

## 构建说明与产物契约

唯一本地构建说明是[source/readme.md](../../source/readme.md)。source/build.bat→tools/build.py→CMake使用原生MSVC Win32、CMake和Ninja，分别链接精简发行EDSlash.asi及完整debug/EDSlash_debug.asi。缓存分别为.build/msvc-release及.build/msvc，发布为release。

发行和调试独立链接，均为/O2。完整调试件使用debug/EDSlash.pdb；精简正式件的未压缩ASI与PDB保存到debug/正式版符号，各自GUID/age须匹配，禁止跨配置使用。正式发行默认UPX --best --lzma，只压发行副本；--checks-only执行检查而不更新发布。另有4项Python配置同步回归及4项Controller真实样本地址回归，正式发布只补已有TOML的模板新段/键，保留原值/绑定/注释；语法错误或并发改动拒绝覆盖。运行只装其中一件，当前正式发行每轮重新压缩并验证UPX。

产物须为PE32/i386 DLL、非零入口、唯一InitializeASI，入口/导入/重定位及真实加载通过；无外置SDL或编译器运行库要求。未知宿主和非0x400000加载不访问固定游戏地址。分别核对两种配置的PDB，验证其GUID/age与各自ASI的CodeView记录一致，并拒绝跨配置符号；UPX解压件与精简压缩前件比较运行段及导入语义；发行包不带PDB。

## 离线验证职责

GitHub Actions调用相同本地构建入口，SDL使用仓库完整源码。只有main成功任务更新dev-auto；内部验证同源正式/debug双产物，自动ZIP的plugins目录包含正式ASI与默认TOML；根目录附带cnc-ddraw 7.1和Ultimate ASI Loader 9.0的官方32位发行件，Shaders已展开内嵌包，原样许可集中在Third_Party_Licenses。许可证与上游文件逐字节一致，SunPro声明明确为源码注释片段；中文说明不插入许可正文。打包严格核对清单、CRC、原件字节、默认配置及源码身份；缺件、空白改动或旧产物均拒绝。ZIP SHA仅在任务间传递。CI没有游戏EXE时跳过真实样本检查，不宣称实机通过；远程任务结果查看Actions。

CTest以当前source/CMakeLists.txt登记为准，按输入/方向、战斗/菜单/调查、Guard真实TOML、QOL定位/提示、共享契约/启动失败、焦点边界/视觉、原设置/模组设置、日志/异常、静态SDL及ASI加载分类验证。新增测试直接完善各职责，不在本文维护逐轮数量。四份准确EXE逐一核SHA、签名、CALL/虚表及独立来源；模拟地图不能替代原静态选择器地址复核。

宿主覆盖调用约定、对象/参数、状态隔离、角色切换、原子保存和错误路径；虚拟设备覆盖采样、映射、断线与震动；非游戏加载覆盖入口及重定位。这些检查不能代替原游戏碰撞、动画、角色资格、真实设备或性能验收。测试计数与执行结果按实际版本归入《版本与更新记录.md》。阶段执行证据只进入更新记录；新菜单的真实高亮/动画/物理输入交接仍须两作实机。

后台日志回归同时覆盖宿主实际代码页及1252／936／UTF-8三组受控代码页。包装仅改变测试目标的CP_ACP解析，仍使用Windows真实转换API，不进入生产ASI。路径断言按ANSI接口实际返回的内容核对UTF-8输出；代码页不能表示的汉字可能在接口返回前已替换，日志层不承诺恢复丢失字符。UTF-8标签、中文记录、并发完整性与容量不足不修改输出仍严格检查。三组可执行文件各有独立输出目录，允许并行测试。

## 显示与平台回归

本体/外传分别检查字体、Strategy进出、标题动画、HUD居中、辅助窗口层级与点击、顶部0x0B/0x0E按钮按压动画。BaseHeight=480与16:9应得TargetWidth=856；其它极端比例不继承该比例的实机确认。

Steam专项分别检查完整JMM apply、语言资源切换、cnc-ddraw OpenGL、class atom与官方EDIT链。Controller已接入Steam准确散列及地址表；显示专项成功不能替代Steam手柄实机验收。

## QOL回归

名称true/false、拾取mode0～4分别检查。interval_ms控制扫描周期，drop_delay_ms控制每个物品生命周期等待；二者独立，0不绕过原落地门。手动Z不受自动分类门影响。背包满、过滤和未入包不产生成功提示；金币/堆叠/新槽提示使用实际增长。反复掉落、切图、关闭扫描与大量物品场景均需检查。扫描日志只证明发起调用。

## 手柄与配置回归

详细顺序见[手柄实机验证说明](手柄实机验证说明.md)。两作均覆盖移动、交接、X/Y衔接、RT/RB、必杀、防御、闪避、图标与拾取。配置热应用要通过实际保存接口，在闪避期间保存、结束后确认新快照与下一次距离；重启读取不替代该测试。

实机记录须说明角色/地图、设备、配置、产物与完整日志。现有基础/性能确认保留覆盖边界；新增Guard热应用待实机。LB药品暂假定，完整菜单仍有后续页面；自有MOD设置页已实现，仍待实机。

BUG复测优先使用release/debug/EDSlash_debug.asi及旁边TOML，完整调试件包含源码行/符号并保留SDL动态API；精简正式版问题使用release/debug/正式版符号中的匹配ASI/PDB定位。安装目录只加载一份EDSlash ASI，替换旧件，不能同时放发行与_debug两份；仍由用户启动/停止游戏，不自动附加调试器。

异常记录回归在自有宿主喂入上下文并写独立临时文本，验证寄存器、UTF-8/CRLF、递归和继续原异常链；不制造游戏崩溃。动态框回放提供真实动画/源图/目标尺寸，逐片校验源范围，不能仅以目标矩形参数正确代替图像安全。## 产物体积与裁剪

### 体积来源

ASI包含三模块、静态SDL和所需编译器运行库。机器码、数据、异常展开、导入/导出、重定位及头部参与运行，CodeView记录标识外置PDB，完整源码符号存放在PDB中。发行与debug独立链接，UPX只处理精简发行件。

目标文件/静态库体积不等于最终链接分摊，应先做链接映射。.bss虚拟大小主要影响内存，不能算作磁盘字节。实测字节数与临时实验留在更新记录。

### 双产物与裁剪

正式版关闭SDL动态API，完整debug保留上游配置；两者均为/O2，各自交付匹配PDB，不再要求跨配置运行段相同。两种配置分别通过完整CTest及PE/入口/导入/重定位/加载验证。正式发行默认UPX --best --lzma压发行副本，debug和PDB不压缩；已有TOML只补模板缺键并保留原值，部署只选一种。每轮正式构建同步压缩发行配套配置，release/upx保留相同压缩副本，checks-only不发布。

### SDL与性能边界

完整debug的动态API表指向REAL实现，会保留像素/PNG/WAV等公共代码。正式版在.build/msvc-release/SDL-source完整派生副本关闭动态API，配合/OPT:REF删除未使用实现；仓库SDL原件保持原字节，不能用命令行宏冒充关闭。正式版不支持SDL3_DYNAMIC_API运行时替换。手柄后端、映射、Haptic、Sensor均保留；Video公共代码为官方DirectInput检测保留，运行只初始化GAMEPAD。

进一步裁剪先核链接映射和上游支持选项，不盲删源码/后端。磁盘、内存与CPU分别判断；剥离符号不是掉帧改善证据。性能用聚合日志和同场景实机对照，产物体积/散列按实际构建记录归档。

## 发行结构与缓存

根docs放正式技术与接档，source放代码/配置/工具及唯一readme.md，release放压缩发行/debug/UPX同件副本，根.build放可再生缓存。固定SDL源码仍在thirdparty并随源码环境提供。缓存和临时截图不构成接档依赖；构建入口会重建缓存。文档整理不运行构建、不更改产物。

正式构建成功后默认清理根.build；--checks-only或失败保留诊断，--keep-build保留增量缓存。随机核心195611项脚本回归和新名称窗口适配纳入构建，原始证据/正式产物不放缓存。

UPX解压复核：除.idata导入元数据外，全部运行段字节与虚拟布局须完全一致；导入元数据允许UPX重排，但逐项IAT地址、DLL名及函数／序号必须一致。实际代码字节及导入DLL损坏副本均应被拒绝，不执行损坏副本。此检查不放宽debug与压缩前发行件的严格逐段一致规则。

随机生日UI回放使用固定种子覆盖十二个月和二月29日，日期是否合法及原setter调用次数仍严格断言，不以随机抽样是否恰好出现某天作为构建结果。设置窗口无角色回放检查拒绝编辑、提供反馈和草稿／绑定不变，不依赖提示文案的具体措辞。窗口回放在.build使用系统分配的独立临时配置并写默认模板，失败残留不因进程编号复用被下一次读取。

## UPX空调试目录槽位

PE调试目录可以被压缩器完全移除，也可以保留其位置与长度但将记录清零。验证器接受全部28字节为零的空记录，它不提供可忽略的数据区；非空的未知类型记录仍然拒绝。除已解析导入和调试元数据外，运行段布局、代码和业务常量必须一致。统一构建包含真实PE回放：全零槽位通过，未知非空槽位以及代码、只读数据、导入DLL损坏均被拒绝。

自动包依赖整合：source/tools/release_dependencies.py固定官方v7.1.0.0与v9.0.0资产及各下载SHA-256，在构建后、打包前下载。打包器在内存合并Shaders/shader-package.zip到包根，同名覆盖，不产生Shaders/Shaders；保留原内嵌ZIP。禁止越界路径、链接、重复名称及异常解压体积。所有依赖与着色器保持原字节，许可证从固定标签获取。着色器含GPL及CC BY-NC-SA 3.0，源码许可头保留，附GPLv2与CC许可原文及作者声明；完整包不能宣称全部可任意商用。远程Actions及游戏实机结果需分别确认。

自动发行说明：发布任务按context.sha读取docs/自动构建分发说明/发行说明.md，置于Release正文最上方；其后为分隔线、当前提交与构建链接，以及从本次构建提交开始最多五条提交标题。缺失或空说明在修改标签前拒绝发布。docs/自动构建分发说明/使用说明.txt按原字节加入ZIP根目录，打包清单与回读核对覆盖该文件。

## 测试断言与编译器兼容验证

测试共用source/tools/TestAssert.h：TEST_CHECK接收计数器、条件和失败动作，条件只计算一次，保留各宿主的错误信息及return/exit行为；TEST_FAIL用于确定失败的路径，编译期页数等约束使用_Static_assert。不要新增直接对常量做if判断的CHECK副本。未关闭C4127或/WX，业务代码的常量条件仍受检查。test_assert与test_assert_exit覆盖常量检查、单次求值、计数、失败返回以及准确的exit状态和诊断。

本地执行`python source/tools/verify_compilers.py`，依次使用已安装MSVC14.44与本机默认MSVC完成checks-only构建和全部离线验证，不更新release、不安装编译器。可用`--versions 14.44 default`调整顺序或范围。手动指定编译器时设置进程环境变量EDSLASH_MSVC_VERSION，例如PowerShell中`$env:EDSLASH_MSVC_VERSION = "14.44"`，之后运行统一构建；恢复自动选择用`Remove-Item Env:EDSLASH_MSVC_VERSION`。指定版本缺失或与实际路径不符时停止，不静默回退。EDSLASH_VS仍可指定已有VS安装目录。CI固定选择14.44系列，并在构建日志打印实际x86编译器路径。双编译器入口每次重新探测环境，避免继承开发者终端导致重复验证同一编译器。所有中间文件位于根.build。


## 固定依赖下载与Actions缓存

release_dependencies.py为每份固定依赖打印名称、URL和尝试次数。连接／读取超时、连接中断、读取不完整及HTTP408/429/500/502/503/504最多尝试四次，网络超时30秒，间隔2、4、8秒；404等永久HTTP错误、超大响应及SHA-256错误立即拒绝。网络阶段不写目标文件，完整字节核验通过后在同目录临时写入、flush/fsync并原子替换，失败清理临时文件。已有缓存重新核验摘要，通过后不请求网络；损坏缓存停止，不覆盖证据。

Actions在下载前使用官方actions/cache/restore@v6恢复runner.temp/edslash-dependencies；下载成功后save@v6保存已核验缓存。键含runner.os与下载脚本hashFiles，清单、版本或摘要变更会换键。缓存服务不可用不阻止正常下载，缓存不是完整性豁免；下载步骤15分钟上限。打包和发布仍必须依赖下载／摘要／ZIP校验成功。官方说明：https://github.com/actions/cache 。

test_release_dependencies.py八项测试含超时后成功、四次耗尽无缓存、临时HTTP与404、错误摘要、缓存免网络、提交失败清理以及原嵌套ZIP／路径拒绝。固定六文件实际下载及二次缓存复用已在本机通过；不能据此声称GitHub runner实际网络和远程工作流已通过。推送修复后触发新运行，旧运行Re-run仍使用旧提交。
