# 手柄首批菜单实现与验证说明

## 范围与当前证据

Menu.c/h属于统一Controller，本体1.05与外传2.01的Steam／非Steam四份准确基线同时实现。已完成公共路由、独立焦点、方向导航、原生A/B和输入隔离，并接通标题JM19、游戏内系统JM2D、资金数字输入JM98的确认取消。代码与宿主验证完成，实际GUI高亮、原动画和物理来源交接仍待两作实机。

这不是全菜单完成：读档及其X原删除确认已接通；新建/设置内部的手柄A确认/文字/列表/滑块仍未接通。JM98是带JM99数字文本的资金输入类，不能宣称已经覆盖删除/覆盖/退出等所有弹窗。数字文本编辑、自有MOD设置和其它页按[菜单需求清单](手柄菜单操控需求清单.md)后续批次推进。

读档/删除确认、默认读取及音效、原鼠标图样标记见[读档与原生反馈说明](手柄读档与原生反馈说明.md)，独立调查见[调查扇区与静态交互说明](手柄调查扇区与静态交互说明.md)。

## 玩家操作

| 场景 | 操作与行为 |
|---|---|
| 本批页面 | 十字键或左摇杆选按钮；A触发当前按钮原生业务；B当前取消/返回 |
| 标题根 | 默认读取游戏；B和START不退出程序；选择退出后A才调用原版退出 |
| 系统菜单 | START从世界沿原Esc链打开；默认继续；B或START关闭；A选择继续、原保存/离开流程或设置 |
| 资金确认取消 | 默认确认，左右可移到取消；A执行当前按钮，B直接取消；金额仍来自原数字文本 |
| 开关页及接管 | 所有按钮/扳机松开，两杆回中一次；旧A、攻击键或推杆不会触发新页或关页后角色行为 |
| 物理鼠标/键盘 | 实际新输入接管原版；再用新手柄输入接回，菜单重新建立独立默认焦点，并等待释放 |
| 未实现页面 | 保留原先B→Esc及十字键→箭头桥，A不写Enter；需要时用物理鼠标或既有BACK+START救援模式 |

导航按真实控件中心几何：只选所推半平面的近邻，边缘保持原位置。按下立即移动，首次按住350毫秒后重复，此后110毫秒重复；左杆导航阈值为轴力度0.55。右杆不绑定此批页面。没有为填满按键加入X/Y、肩键或扳机菜单业务。

## 路由、焦点与输入隔离

公共Menu_Context优先检查真实capture；对子capture最多回溯八级父链归一化，未知capture仍阻塞世界。顶层链最多256项，要求真实活动标志和资源属性13等于1，排除HUD；资金模态页优先。物理来源可参考实际+40路由，手柄来源使用真实活跃页链，不把光标所选的+40作为自己的页面来源。不改CJMMng迭代器、链顺序或控件屏幕坐标。

每页只保存根对象、业务ID及需要的焦点区域；每次从root+9C、child+8子链重新收集本批白名单。要求child+A4仍是该页、child+64打开以及几何尺寸有效，最多128个节点/64个候选。不长期保存子对象裸指针，隐藏/移除按钮不再可操作。只读active标志，避免原active查询顺便改B8 latch。

Menu_Update在Controller键盘采样后、Game_Keyboard前运行，标题无世界/玩家也可用。已消费本批输入不桥接Esc、Enter或世界快捷键；Game_Update保留菜单和中立门阻塞。未知页没有猜测确认回调。物理WM_KEYDOWN仅新按下边沿接管，自动重复不抢回来源。

页面/root变化、Show关闭重开、来源接管、失焦/断线/模式变化建立中立门。门覆盖所有按钮、双扳机与双杆，释放帧自身不执行确认。一次A只提交一次，即使业务原地拒绝也需松开再按。中立门仅影响当前/待退出菜单或真实GUI，纯世界物理/手柄交替不会吞第一次攻击。正常关页回中后退出门，不反复重新上锁；后续新RT或攻击可以立即重新进入战斗层。

## 原生业务与视觉

标题调用原激活入口，本体保持按钮激活动画等待，外传保持即时分派；动作进行时不导航、不重置精灵、不重发确认。按钮共同1F..23，外传增加A7；标签未有资源证据时不擅自命名额外页面。

系统仅绑定2E、30、31：原继续/关闭、原保存相关阶段迁移、原设置。2F在当前入口没有业务，手柄不绑定。业务前把独立选项投影到root+A8，调用原系统主操作，三个原栈参数未使用，传空值；不伪造鼠标管理器。

资金确认走原+3C实现，仍解析JM99文本后回调owner；取消用原ShowHide(0,0)。默认金额及上下限仍由原逻辑控制，本批不直接改金额或owner字段。

视觉用原按钮状态：标题/确认按钮切换精灵+40并调用原动画重置，系统用原纹理源偏移接口。+58/+5C是纹理源偏移，不是移动屏幕坐标。原Tick返回后重投影；原hover被手柄隔离后不会用光标覆盖焦点。物理来源恢复完整原hover。精灵数不足或损坏资源不越界；真实视觉效果仍需实机。

## 离线检查与实机验收

test_menu复用32位test_game fixture，链接真实Control/Menu/Game与依赖；覆盖两作无玩家标题、方向重复/边缘/隐藏、外传A7、原业务ABI、真实来源恢复、Tick重投影、模态优先、页面/来源门、关页后技能及攻击恢复、未知页不注入Enter、断线失焦，以及45个槽与七处局部调用逐一失败回滚、显示Draw兼容。日志分类、列表编排、技能学习和连招上下区域业务另见对应说明。测试工具及限制见[工具说明](工具说明.md)。阶段执行数、产物散列与失败修复过程只存[版本与更新记录](版本与更新记录.md)。

两作分别用当前发行或完整版测试：

1. 标题不动鼠标，十字键/左杆选项有高亮，A打开原页；本体激活不截断动画。标题B/START不会退出；退出只在正确选项A后执行。外传额外项按实际显示确认。
2. 游戏中松开战斗输入后START打开系统页，默认继续；分别检查B/START关闭、A继续与打开设置。离开游戏属于原保存相关业务，应在正常存档条件下单独核对。
3. 拨杆或按键期间开/关页，释放后再操作；菜单期间X/Y、RT/RB/LB、LT与双杆不得漏发攻击/技能/投掷/药品/必杀/闪避。关页回中后新攻击/RT可以工作。
4. 物理鼠标/键盘接管原页，再新按手柄接回；静止鼠标无论留在哪个按钮，手柄默认和后续选择都由自己的焦点决定。移到别的按钮是实际物理输入，应按既定方案接管。
5. 在原资金操作已经打开JM98且金额准备好时测试A原确认、右选取消后A、B取消。金额编辑仍用原输入；不得据此记录为数字编辑或通用弹窗已完成。
6. 断线、窗口失焦/恢复、返回标题、再次进入菜单；旧A及推杆不误触，新业务仍可操作。分别开关HUD居中/辅助GUI层级测试真实高亮。

日志查看[菜单路由]、[菜单焦点]、[菜单操作]及[输入来源]，记录游戏、角色、产物与完整EDSlash.log。单作成功不能替另一作；编译和宿主不能替实际GUI动画、设备时序或性能确认。
