# 手柄统一集成边界与设计依据

## 集成职责

Controller已接入统一EDSlash.asi，ControllerModule连接Runtime，原生战斗业务保留模块内。Runtime提供身份、公共输入、配置、日志和事件。独立入口、两份INI、外置SDL与兼容升级不构成当前契约。

## 配置复用

TOML核心、描述表、候选快照、原子保存已纳入Runtime/Toml.c、Config.c、FileIO.c，不依赖Castle DLL或另一工程路径。schema=1，缺失生成默认、损坏不覆盖、保存核对外部修改。按游戏/创建角色selector/槽保存selector与手侧，保持原默认来源。输入边界、动作结束和重启应用分开，详见统一配置说明。

## 输入与体验契约

公共帧保持原位置，Controller采样/解析后处理，QOL在原input_update返回后END扫描；END不是全业务帧结束。设置焦点须阻止世界动作泄漏，宽屏关闭/HUD不居中/QOL关闭时也能使用。

不得降低已确认死区、前探、走跑、X/Y、RT/RB、必杀、防御闪避、鼠标交接、断线/失焦/切图、图标/文字/点击体验。热路径不读配置磁盘或重复采样。性能按同场景比较，编译不替代实机。

## 剩余范围

基础迁移与性能已获实机确认；设置热应用仍待实机，自定义绑定/设备/开关按覆盖限定。完整菜单、双扳机动作菜单已接入，自有MOD设置页已接通原暂停、配置保存与热应用，仍待实机。方案变化和迁移过程见更新记录。
