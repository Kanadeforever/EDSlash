# 手柄菜单操控需求清单

## 当前范围与状态

本清单面向统一Controller，本体1.05与外传2.01的Steam／非Steam版同时实施。标题/系统/确认取消、读档删除、NPC、技能日志已有当前基本正常反馈，未逐作列明。新增读档上下跨页、日志左右翻屏、背包/储物箱第一批已离线通过，实际GUI/物品业务/性能待两作。其它未实现页仍有限B/Esc/方向桥，A不注入Enter。操作和边界见对应技术说明。

游戏原有界面操控先推进；我们自己生造的MOD配置界面后置，入口F12/L3+R3保持约定。双扳机右杆已接入原左右手动作菜单，R3换侧、松任一扳机确认，不与自有MOD设置页混称。

## 所有页面共用的前置工作

| 工作 | 必须形成的行为 |
|---|---|
| 页面路由 | capture/modal优先，其次实际顶层页面，再识别内部子页/区域；隐藏常驻对象不算可操作页 |
| 插件焦点 | 保存当前页、区域、项目/格/按钮和激活代次；页面关闭/重建/切图不留悬空指针 |
| 方向导航 | 十字键，建议同时支持左摇杆；按下立即移动，按住有延迟重复，回中解除；布局适配真实控件几何 |
| 可见反馈 | 明确高亮、列表自动滚动、物品/技能名字图标和详情随焦点；不依赖鼠标位置 |
| 原生业务适配 | A确认/操作，B按当前状态取消/返回，调用具体页面已有业务；不用统一Enter或假鼠标点击 |
| 页签与区域 | LB/RB按页面执行真切页或已显示区域切焦点，不擅自打开隐藏区域 |
| 输入捕获 | 菜单处理过的输入不漏调查/攻击/技能/道具/药品/必杀/闪避；新页不继承上一页held确认 |
| 物理交接 | 用真实鼠标/键盘或新手柄操作接管，焦点/原生数据状态同步，救援鼠标模式保持独立 |
| 生命周期 | 标题无玩家、窗口失焦、断线重连、模式切换、切图/返回标题、控件销毁均清理正确 |
| 验证范围 | 两作、宽屏开关/HUD布局、键鼠交替、按住切页/关页都检查；热路径不新增磁盘I/O或全库每帧扫描 |

参考资料的“真实鼠标格中心/移动鼠标桥”属于旧建议，不作为本实现。控件坐标可用于几何导航/绘制计算，不变成伪造鼠标输入。可以复用鼠标按钮原本触发的具体业务事件，但手柄保持自己的选择来源。

## 建议批次

1. 公共页面路由/焦点/输入捕获最小链，完成标题主菜单、游戏内系统菜单、确认取消框。先形成从标题进游戏、打开菜单、操作并返回、键鼠交接的闭环。
2. 读档、新游戏流程、数字输入、原设置、属性/日志/对话/信息等基础页面。文本输入另做明确方案；不能漏掉外传额外页。
3. 技能/日志及背包/储物箱第一批已完成源码和离线验证；商店买卖/合成/镶嵌/护身石已扩展，接续装备/快捷分配和数字输入，覆盖原报价、类型限制和交易失败。
4. 合成/镶嵌/护身石多区域；页内状态独立维护，不能把业务不同的右键统一映射为B。
5. 自有MOD配置和技能绑定界面，沿现有安全保存/应用接口验证真实热应用；双扳机动作菜单已接入，继续实机核对。

统一建议：A当前合法操作、B当前取消/返回，LB/RB只在确有页签/区域语义时启用。X/Y仅在原业务明确并且对玩家有用时绑定；右摇杆滚动、触发器快调、文字输入等尚未定，不为了填满按键添加功能。

## 第一批完成标准

两作标题/系统/确认取消都能全手柄完成所覆盖流程；任何鼠标位置不决定手柄选项；焦点可见、隐藏项不可选、按住不重复确认。弹窗/页切换/退出后不漏战斗输入，不打开控制台；断线/失焦/切图/物理交接正确。离线接口及焦点回放先验证，再分别实机验收。菜单业务变化不顺带重调已认可的战斗/移动手感。
