# 手柄菜单操控需求清单

## 当前范围与状态

本清单面向统一EDSlash项目的Controller，非Steam本体1.05与外传2.01同时实施、成对验证。标题/系统/资金确认取消、读档/删除确认、原光标标记及NPC对白/选项已接通。用户确认调查/NPC/手动换区修正当前测试没问题，未逐作列明，不扩大为两作全面验收。日志分类/列表和技能学习/连招编辑已获当前测试正常反馈，删除补位修复通过双版本离线验证、待实机，见《手柄技能与日志界面说明.md》；其余未实现页仍仅B→Esc/方向键桥，A不注入Enter。

游戏原有界面操控先推进；我们自己生造的MOD配置界面后置，入口F12/L3+R3保持约定。LT右摇杆是原生左键动作弹出菜单，按用户既定安排最后做，不与普通菜单或MOD设置页混称。

## 所有页面共用的前置工作

| 工作 | 必须形成的行为 |
|---|---|
| 页面路由 | capture/modal优先，其次实际顶层页面，再识别内部子页/区域；隐藏常驻对象不算可操作页 |
| 插件焦点 | 保存当前页、区域、项目/格/按钮和激活代次；页面关闭/重建/切图不留悬空指针 |
| 方向导航 | 十字键，建议同时支持左摇杆；按下立即移动，按住有延迟重复，回中解除；布局适配真实控件几何 |
| 可见反馈 | 明确高亮、列表自动滚动、物品/技能名字图标和详情随焦点；不依赖鼠标位置 |
| 原生业务适配 | A确认/操作，B按当前状态取消/返回，调用具体页面已有业务；不用统一Enter或假鼠标点击 |
| 页签与区域 | LB/RB按页面执行真切页或已显示区域切焦点，不擅自打开隐藏区域 |
| 输入捕获 | 菜单处理过的输入不漏调查/攻击/技能/道具/药品/必杀/闪避；新页不继承上一页held确认 |
| 物理交接 | 用真实鼠标/键盘或新手柄操作接管，焦点/原生数据状态同步，救援鼠标模式保持独立 |
| 生命周期 | 标题无玩家、窗口失焦、断线重连、模式切换、切图/返回标题、控件销毁均清理正确 |
| 验证范围 | 两作、宽屏开关/HUD布局、键鼠交替、按住切页/关页都检查；热路径不新增磁盘I/O或全库每帧扫描 |

参考资料的“真实鼠标格中心/移动鼠标桥”属于旧建议，不作为本实现。控件坐标可用于几何导航/绘制计算，不变成伪造鼠标输入。可以复用鼠标按钮原本触发的具体业务事件，但手柄保持自己的选择来源。

| 页面/系统 | 需要完成的业务 | 导航与特殊边界 |
|---|---|---|
| 标题主菜单JM19 | 选择新游戏/读档/设置/退出/信息，A触发原主业务 | 按真实几何/可操作按钮，标题根B不猜一个父页面；外传额外A7→A6单独覆盖，正式标签未确认不乱命名 |
| 游戏内系统菜单JM2D | 继续、设置、离开当前游戏的原流程 | A当前按钮，B原关闭；保存与游戏状态迁移由原业务执行 |
| 确认/取消JM98 | 原确认与owner回调、原取消关闭；该类同时承载资金整数输入，不泛指所有退出/覆盖/删除框 | A当前确认业务、B取消，弹窗优先，重建后等待旧按键释放；数字编辑另批实现，不能泛调用所有GUI的虚表+3C |
| 数字输入框 | 金钱存取等原数值业务，合法上下限与文本回显 | 左右加减/按住重复，步长可后续定；不把它误当商店通用购买数量框 |

| 新游戏角色JM1A | 角色项选择与原PlayerInitSelector提交 | 两作角色集合分别检查，B回标题 |
| 新游戏名称/难度JM9C | 名称框/难度/确定返回控件，原重名/非法名校验 | 文字输入单列方案；不因能按A就宣称全手柄中文命名，原EDIT/IME链保留 |
| 原游戏设置JMAA | 滑块/选择按钮/返回的原业务 | 几何导航与调值，沿原返回语义；不在此追加MOD参数或改原set.ini |
| 属性/装备信息 | 打开/关闭、必要信息滚动与可操作项 | 不给只读内容强造A动作，不假定原游戏有可手动加点按钮 |
| 任务日志JM63/列表 | 当前项、长列表滚动与分类切换 | 原选择数据与可见列表一致；LB/RB切78..7B，A无独立业务时留空 |
| NPC对话/动态选项 | 当前有效选项及原脚本分支，普通文本推进/关闭 | 有效2A子项与脚本记录对应，选项重建清理焦点，不选择隐藏/失效记录 |
| 滚动信息JM1C/外传列表 | 原关闭、实际列表选择/滚动 | 只有查明的业务才绑定，不从旧猜测造特殊动作 |
| 背包/装备/快捷槽 | 二维格选择、物品详情、原使用/拿起/放置/装备/快捷分配 | A按当前物品操作状态，B先取消进行中的操作再按原关闭；原物品限制保留 |
| 仓库 | 本地格与背包间的原转移/交换 | 只在已显示区域切焦点，保持local→逻辑槽映射，不直接改库存数组 |
| 商店 | 商品/背包选择、买卖模式与原交易、资金/空间不足反馈 | LB/RB切57/58，报价跟焦点；原商店整组交易，不擅自发明数量买卖 |
| 宝石合成 | 七槽及原合成按钮/配方限制 | 物品格和操作按钮两种焦点，不绕材料资格 |
| 宝石镶嵌 | 十二槽、装备与宝石原操作 | 保留原接收槽限制，与已显示区域切换 |
| 护身石 | 五槽及原装备/交换流程 | 独立区域焦点，不并成一个全局物品索引 |
| 技能页JM7D/7F | 技能节点、详情、原学习/选择业务 | 按当前角色原数据和真实可用控件；LB/RB切技能/连招，不误发战斗RT快捷 |
| 连招编辑JM7D/80 | 四套、原追加/按位置删除及原保存 | A原确认；删除中间停补位项，删末项停新末项；X切上方清单/下方技能；Y循环1～4套；B关闭；LB/RB切两页。原游戏没有独立拖动排序业务，不擅自新增 |
| 自有MOD配置界面 | 描述表设置、按角色技能绑定、保存/生效/待重启/错误反馈 | F12/L3+R3后置，调用现有TOML服务；即时不可用不等于技能未学会，不保存最终Method |
| LT右摇杆左键菜单 | 原生左键GUI展开/聚焦/松LT选中 | 保持LT显示与防御，回中保焦点，松LT选择不自动出招；最后做，不另造轮盘 |

物品“拿起/放置”等仍需核对实际原操作状态和入口，表中列的是必须覆盖的用户操作，不承诺已有安全通用接口。文字输入、自绘焦点和控件资源的具体实现也未选定。

## 建议批次

1. 公共页面路由/焦点/输入捕获最小链，完成标题主菜单、游戏内系统菜单、确认取消框。先形成从标题进游戏、打开菜单、操作并返回、键鼠交接的闭环。
2. 读档、新游戏流程、数字输入、原设置、属性/日志/对话/信息等基础页面。文本输入另做明确方案；不能漏掉外传额外页。
3. 技能学习/连招编辑及任务日志已按用户指定优先完成源码和离线验证。接续背包、装备/快捷分配、仓库、商店，覆盖格子详情、操作取消和原交易失败。
4. 合成/镶嵌/护身石多区域；页内状态独立维护，不能把业务不同的右键统一映射为B。
5. 自有MOD配置和技能绑定界面，沿现有安全保存/应用接口验证真实热应用；LT右摇杆菜单按既定要求最后做。

统一建议：A当前合法操作、B当前取消/返回，LB/RB只在确有页签/区域语义时启用。X/Y仅在原业务明确并且对玩家有用时绑定；右摇杆滚动、触发器快调、文字输入等尚未定，不为了填满按键添加功能。

## 第一批完成标准

两作标题/系统/确认取消都能全手柄完成所覆盖流程；任何鼠标位置不决定手柄选项；焦点可见、隐藏项不可选、按住不重复确认。弹窗/页切换/退出后不漏战斗输入，不打开控制台；断线/失焦/切图/物理交接正确。离线接口及焦点回放先验证，再分别实机验收。菜单业务变化不顺带重调已认可的战斗/移动手感。
