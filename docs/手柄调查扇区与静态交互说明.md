# 手柄调查扇区与静态交互说明

## 当前机制

Inspect.c与战斗解析分开保存调查句柄/事件种类；不从MouseManager+40取静态候选，不写鼠标坐标或CombatTarget。角色平面世界X/Y计算正面总角度90度，推左杆时使用等距逆投影方向，松杆时反查原角色8/16向真实朝向。持续调用原WorldHover提供游戏自己的高亮/名字，不另画锁定效果。

动态候选走实际角色链、句柄代数与self校验，要求动态类1E..64、非当前玩家、失效字段为0、交互route非0、原ready字段非0。不限死28类型，原两轴格差均≤2，正面扇区中选最近。A保留原句柄占用门，原事件19提交；不能以阵营/敌人关系代替NPC资格。

静态不在角色链。读取原静态选择器使用的全局地图指针（558E48/589E30），按配置距离确定局部格范围，最大17×17共289个19字节记录并用真实距离裁剪；检查地图范围/地址，静态按格flags88取C句柄，掉落从E句柄独立取得，不套静态flags。普通静态按原资格谓词：BC状态0或2允许，其它状态拒绝。完整选择器在谓词非零时返回对象；旧实现/资料的相反解释错误，原指令证据另存，不改只读参考资料。正面探查区内87/88提交23，实际邻接资格仍由原消费者控制；89提交24。80..86按原基础技能组及独立世界点进入既有技能解析/资格/历史链，原事件10作用；不会让鼠标或附近敌人改目标点。掉落类17按原21拾取，不受QOL自动过滤设置限制。其它原静态候选保持原点击移动语义，不擅自执行未知脚本。96另用原TransGo/go谓词检查，只接受原20消费者支持的C/D类，不把全部96当机关。按物件占用格选近侧，不猜Renderer内部位置。

原WorldMouseMove在resolver之后还能再次写WorldHover，Controller包装其唯一调用点：普通手柄投影独立调查/已有有效战斗目标，物理来源完整执行原函数。没有自己的目标时清除鼠标指向造成的提示；清理只撤仍属于自己的高亮，旧地图/其它来源不覆盖。

## 可配置最大距离与性能

统一键[controller.interaction] max_distance，默认160世界单位，允许16～480，64=1格。旧方形扫描最远格中心约317，以用户确认的320整数基准，默认一半、上限1.5倍。所有调查候选先受真实距离与90度扇区裁剪，原对象资格和原互动范围仍保持；配置上限不代表任何对象都可在该距离执行。

缺项用160。模板来自Runtime描述表，已有玩家TOML保留，手工添加键后重启读取；不恢复INI或逐帧读磁盘。运行时经Config保存接口的修改按输入边界应用。

一次扫描只读取一次地图头，同一对象多格只查一次原资格，但仍比较近侧各格；攻击/忙碌时不做调查格扫描，先几何排除再解析资格。缓存只在当前调用内，不跨帧留物件指针。性能日志增加调查探测，属于手柄业务嵌套分项，不与总项相加。

## 原TransGo出口进入与范围

用户补充原换区行为是鼠标图标改变后左键触发。两作原谓词432730/43BDD0先检查A3状态，再检查96类脚本中TransGo/go；原主动作通过后提交20，参数依次为地图格X、格Y、目标句柄。原pending20通过玩家周围一格的格记录匹配，后续保留AF状态、提示/资格、脚本执行与地图事务。

手柄读取正面近身的96候选并调用相同谓词；进入区域只聚焦和显示，必须在原一格邻域内新按A才提交20；推杆靠近本身绝不换图。远处聚焦不等于已进入，A不会在区域外提前排换区请求。原87/88仍A→23，89仍A→24，均不自动触发，不能把24类泛称出口。

只维护已经由A提交的请求，原pending20尚在处理时不让前探移动覆盖；原事件没有进入处理时最多等600毫秒，转向离开可以正常走开。切图/角色/地图变化清理自有焦点；A只接受新按边沿，不以持续推杆在新地图再次提交。闪避/受击等非站立/移动状态不产生普通调查候选；任何状态都不由进入动作自动换区。

EXE链与静态地图全局已四样本交叉核对；本体开门/换区及门高亮已有用户确认，未测试机关仍待验收，外传地图地址修复后的机关/传送阵/换区效果待新实机；不自己加载地图、改脚本、取消原条件或直接执行TransGo字符串。原谓词拒绝的96仍拒绝。

## 实机顺序

两作分别在角色正前/侧后摆NPC、机关、箱子或其它原可互动物件，鼠标停别处；先看持续高亮/名字，再A执行原业务。转身/松杆/走远/隐藏或失效对象要解除焦点，不能选身后物件。不同尺寸物件与墙边单列验证。

测试具体出口：朝出口推杆接近，记录调查焦点及调查进入的事件/句柄、实际换图、失败时地图名与位置。检查同区域不重复请求、转身走开、切图持续推杆不连续返回。不能用NPC成功替代静态/出口成功，也不能用一作替另一作。
