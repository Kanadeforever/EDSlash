# 全方位格挡与动作显示说明

> 文档维护约定：本文按主题维护当前有效的技术正文，不再追加版本更迭、日期同步或发布补丁章节。版本变化、旧版散列、阶段测试与用户反馈统一记入[版本与更新记录](版本与更新记录.md)；技术结论变化时直接修订对应正文。

## 当前机制

- gameplay.combat.omnidirectional_guard=true。有效防御姿态下当前玩家普通攻击可全方位格挡，false恢复原版方向分支，默认true，运行中通过公共配置安全应用。当前玩家手柄与物理Alt共用；未防御角色、敌人和原特殊穿防不被改成免伤。
- 两作方向分支：本体0x41A034，外传0x422543，原指令为6字节jle。包装保存全部寄存器/标志；仅接管有效玩家防御时走已有格挡反应块，其它情况精确重放原条件分支。特殊受击反应仍由后续原版处理。
- 手柄防御开启事件后，用原版转向接口保持事件前角色的朝向，避免原ON事件用鼠标点改变最终朝向；8/16向通过原方向换算反查，不直接写Facing或伪造鼠标。
- 图标不再按Runtime指针改变或单个Runtime结束立即清除。原结束通知捕获收尾动画，活动Runtime续段继续保留，活动指针空后用原动画末帧/帧时长判定收尾，姿态切换或动画结束才恢复。新实际动作成功通知接管图标，移动鼠标本身不撤掉当前动作图标。
- QOL文字保持x=16，起始y=192，行距22、最多6条/5秒仍保持。


## 原版防御门与诊断

两作原最低防御体力阈值都是5.0点：本体常量0x528AEC，外传0x551C08。原防御资格与受击后退出检查都用这个最低值；原版并不等到精确0。最大体力80、每次1%=0.8点时，5.5被扣到4.7，虽仍有体力，防御已退出。全方位开关仍保留此门槛，用户尚未要求修改它。

原受击路径先看0x6A防御状态，再看八向角度差，部分方向进入正常伤害；特殊反应method+0x60=3也不走普通格挡的提前成功返回。全向开关取消已有防御的角度限制，保留特殊反应/硬直/原体力门。当前局部路径未发现独立“防御累计时间或次数达阈值必定破防”的计量，不能据此断言整个游戏绝无其它破防状态。



[防御诊断]观测受击前后HP、体力、防御状态、角色状态、朝向、反应与双方位置；不覆盖特殊行为。有体力仍扣血需区分低于5点、姿态失效、特殊反应及方向开关，不能只凭配置日志推断。

## 验证

全向格挡、图标时长和文字位置有分项用户确认，不能扩为所有角色/外传/攻击类型。局部静态控制流和宿主回放不能证明全游戏没有其它破防状态。阶段产物、散列与日志集中在更新记录。

## 临时动作图标的灰色参数

原HUD按长期右槽选择先计算灰色模式4/透明度32，再调用图标绘制。临时快捷动作替换选择码时，仅当前通过施放资格的活动动作/落点预览使用正常模式0和原正常透明参数-1；坐标、提示及侧别保持，动作结束继续原长期槽绘制。原准备态若不是当前临时动作，不套用这一覆盖。此修正只涉及HUD图标，不等于角色贴图变色已经解决。四版本原指令及失败回归见《手柄空候选与图标资格原始证据.txt》和更新记录。
