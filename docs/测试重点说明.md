# stripe1 测试重点说明

当前测试版：本体 `v0.3.4-stripe1` / 外传 `v0.2.3-stripe1`。

这不是新的 GUI 实验。GUI/Input 继续使用已经实机通过的 layer1d；本轮只验证“最右侧竖条是否由非 8 像素对齐的 TargetWidth 引起”。

## 最小测试顺序

1. 本体，`BaseHeight=480`、`AspectRatio=16:9`：确认日志 `TargetWidth=856`、`stripe1目标宽度8像素对齐余数=0`，观察最右侧竖条是否消失。
2. 本体，`BaseHeight=480`、`AspectRatio=24:9`：确认仍是 `TargetWidth=1280`，作为无问题对照组。
3. 如果前两项符合预期，再测 32:9、8:9、40:9；预期 TargetWidth 分别为 1704、424、2136，余数均为 0。
4. 任一比例下快速打开物品、装备、技能和连招编辑，确认 layer1d 已解决的 HUD 遮挡与按钮输入没有回归。
5. 若竖条仍存在，请保留完整 `DisplayFix.log` 并截图最右侧；不要继续改其它设置，以便保持单变量。

## 预期宽度

| 比例 | stripe1 预期 TargetWidth |
| --- | ---: |
| 16:9 | 856 |
| 24:9 | 1280 |
| 32:9 | 1704 |
| 8:9 | 424 |
| 40:9 | 2136 |

外传可在本体确认方向以后再做等价回归；不能把本体结果直接写成外传实机通过。
