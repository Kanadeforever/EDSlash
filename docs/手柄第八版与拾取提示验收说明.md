## 体力幅度

```ini
[Combat]
ChargeGuardOnHit=1
FreeRun=1
GuardHitCost=12.50
AttackHitRecovery=5.25
DirectionalDodge=1
DodgeDistance=128
```

以上百分比是示例，不替换默认值。发布配置的两个幅度默认仍是-1。GuardHitCost正数表示每次防御受击扣角色最大体力的百分比；AttackHitRecovery正数表示每次攻击实际减少敌方生命值时回角色最大体力的百分比。100.00即全部最大体力，范围0至100.00，支持最多两位小数。最大体力200时12.50扣25，5.25回10.5；以最大值为基数，不以剩余体力或原周期消耗为基数。

GuardHitCost=-1保留角色原防御一个周期的2×原消耗值；AttackHitRecovery=-1跟随防御幅度设置；0关闭对应单次变化。修改后重启。防御空耗、跑步免扣费开关沿用既有设计；实伤恢复属于ChargeGuardOnHit规则，关闭该规则恢复原版周期防御，也不附加命中恢复。仍调用原版体力调整函数处理上限、下限和耗尽。

## 方向闪避

LT+左摇杆按投影换算后的摇杆方向直线闪避，启动后锁定该次方向。松杆回中后才能再触发。原版启动冷却、硬直、当前技能资格和状态动画保留；改变的是状态17的初始化与逐帧位移，不是直接瞬移或伪造鼠标目标。

DirectionalDodge=1开启新位移；0时闪避目标门、初始化和逐帧运动全部回原版函数，原版需要目标或不接受当前启动时仍按原版处理。DodgeDistance是世界单位，64单位=1地图格，默认128=2格，范围16至512；在8个逻辑更新周期内完成。只在新位移开启时生效，改后重启。

每8世界单位检查途经地图格、原版地形资格和占用；斜向跨格同时检查两侧格，遇障碍提前结束，不触发原版近邻找空格的绕行。调用原版grid_commit更新占用表，再调用角色虚表+8的位置setter保持世界位置同步。鼠标接管或松开LT不会让已开始的新闪避突然回圆弧；新原版闪避初始化会清除旧新位移所有权。

## 快捷动作图标

RT技能、RB投掷实际成功建立动作后，右键GUI显示这次动作的原版图标；结束恢复现有右键选择。未被接受的请求不提前冒充正在施放。投掷沿用原版F1-F6使用的角色投掷组图标。只替换右键图标绘制CALL的图标编号与选择参数，坐标、透明度、明暗和快捷提示仍由原版绘制，不改变右键永久装备、套组、库存或原版鼠标对象。

记录角色、世界及活动Runtime，切图、角色变化、结束或新Runtime替换旧动作时停止显示。物理鼠标接管本身不撤掉尚在发动的图标。必杀准备态仍优先显示准备的原版图标。

## 必杀技

LT+A/B/X/Y依次对应角色技能表中第1至4个带原版必杀标志（技能组+0x32>=1000）的组。没有对应组或资格不足只记录原因，不虚构技能。

第一次新按键调用原版prepared_set，只准备并显示图标，不发招。再次新按相同键、且原版准备态仍为同一组时，直接请求必杀；期间按其他键改成其他必杀准备。按住不视为第二次确认。有效窗口用原版HUD+BF4/BF8及游戏自身超时维护，不加插件私有倒计时。超过原窗口后再次按键重新准备。动作真正建立后清除原版准备态，结束恢复之前图标。原技能消耗、资格与连段执行器继续负责实际施放。

## QOL拾取文字

自动和手动拾取成功后，在左侧显示“拾取：物品名 x实际新增数量”。复用原版GBK名称与原版文字绘制函数，经公共UI_DRAW_END事件绘制，最多6条，保留5秒；切图或玩家变化清除。未占用DisplayFix的物理Draw入口，不引入Controller与QOL的私有联系。

拾取入口总返回1，不能拿返回值认定成功；在原版调用前复制名字、模板ID、玩家及背包，在调用后比较相同玩家、场景、背包的实际增长。金钱比较背包+0x20；物品统计136个逻辑槽中对应模板+0x18的数量+0x1C。背包满、过滤或未入包不显示成功文字。名字在对象可能销毁前复制，最长截断保留完整GBK字符。

QOL之外只改source/build.bat接入新增编译单元；公共Runtime/EventBus和DisplayFix实现未改。即使关闭自动扫描，手动拾取仍显示成功提示。

## 两作实机检查顺序

1. 用最大体力可确认的角色，分别设置12.50和5.25，对照受击扣费与实伤恢复；挥空、完全格挡、NPC不恢复，耗尽和上限仍原版。
2. LT+左摇杆朝八方向闪避，松杆重触发；在无敌人、墙边、敌人占位、斜角处测试。改距离64/128比较；DirectionalDodge=0回原版空格式目标闪避。
3. RT技能/RB投掷看到动作期间图标，结束回原图标；检查库存、同槽连投、X/Y交替和物理右键交接仍正常。
4. LT+A/B/X/Y第一次只准备、第二次释放；换键重新准备，等原版图标失效后再次按只能重新准备。按住不连确认，失败资格不误放。
5. 自动/手动捡物、金币、堆叠、新占槽看到左侧提示；背包满、过滤无成功提示，连续拾取最多6条，5秒或切图消失。

LT+右摇杆原生左键技能选择菜单继续后置，本轮未做。新验收通过后才固化实机结论，不替代历史dev7已验收记录。
