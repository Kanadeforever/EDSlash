# 手柄实机验证说明

适用版本：EDSlashController v0.1-dev3 连续方向移动调整版。必须分别测试非 Steam 本体 1.05 与外传 2.01；两作使用同一个 ASI 和 SDL3.dll。Steam 和改版 EXE 尚未列入本版运行基线。

## 一、部署与记录

将 release 中的 `EDSlashController.asi`、`EDSlashController.ini`、`SDL3.dll` 放在游戏 ASI 加载器实际加载的同一个目录。ASI 加载器使用游戏现有安装，本项目未另带或下载加载器。

暂时移出旧手柄实验 ASI，防止多个手柄插件同时注入。首次测试先验证独立手柄，再验证与主插件 BladeSwordQOL 同时加载。主插件内部 EventBus 并未跨 DLL 共享，不能省略共存测试。

日志位于插件旁的 `EDSlashController.log`，每次启动覆盖旧内容。测试完一作后先另存该次日志，再测试另一作，避免覆盖对照。日志应显示对应非 Steam Profile、输入桥安装、SDL 初始化、手柄连接；首次连接或切换模式后请松开所有摇杆、扳机与按钮。

## 三、本版不能当成已完成的功能

- 全菜单几何导航、格子导航、标签页和焦点区域切换、特殊操作以及导航框。
- 方向闪避、LT+ABXY 两次按键必杀技。
- 跳跃/瞬移等动作的长按目标外扩、松开执行；本版 X/Y 仅走普通动作释放。
- 角色专属特殊动作自动识别；RT+L3/R3 默认未配置。
- 连续招式内部的精确重定向、受击震动。
- 静态交互物的独立空间枚举；本版仅复用鼠标已有静态候选，动态 NPC 则做附近筛选。
- 手柄图标、游戏内模组设置页及 Steam 兼容。

尚未覆盖的菜单可以切换鼠标模式完成操作，但不能因此把该菜单的原生手柄导航标为通过。

## 四、dev2 当前重点

本轮先测试进入地图后左摇杆走路、松杆停止、靠近 NPC 按 A、选择好左右手动作后按 X/Y。不要用菜单 Enter 是否响应代替世界操作验收。

若仍无反应，保存本次 `EDSlashController.log`，重点看 `[输入链]`：按键/摇杆是否改变、层是否一直为菜单、门编号与界面 ID、原生帧计数是否增长；再看是否出现 `[移动]`、`[调查]`、`[动作]`。这些字段用于定位阻断点，提交日志并不等于动作执行成功。

## 五、最新实机反馈

2026-09-28 用户确认各方向移动、松杆停止、A 不再开控制台、左右手及 RT 技能/RB 投掷操作已有响应，但移动手感很差。反馈暂未明确覆盖的游戏版本，所以上表仍保留两作分别待验收。下一专项是连续方向与转向手感，不以“八个测试方向能移动”作为手感通过标准；NPC 调查本身仍需独立确认。

## 六、dev3 移动手感专项

只替换 ASI，INI 中没有新增字段时也会使用默认 12 格前探。默认死区仍为 8000，但改为左摇杆二维圆形判断；右摇杆处理保持原状。

两作分别测试：

1. 在开阔地缓慢绕一圈转动左摇杆，观察方向是否平滑变化，尤其靠近水平/垂直方向时是否仍明显吸附。
2. 在刚超过死区与满推两种力度下，比较相同角度的前进方向；小幅斜推不能被吃成停止。走跑仍由 L3 决定，不因力度自动变速。
3. 固定摇杆方向，按 L3 切换跑步，确认速度变化且目标方向不跳；松杆立即停，再推恢复走路。
4. 在墙边、狭窄通道与地图边缘转弯，检查是否因远目标绕路、卡住或走跑异常。
5. 回归 A 不开控制台、X/Y 动作、RT 技能、RB 投掷和鼠标模式。

可选配置：

```ini
[Movement]
LeadTiles=12
```

允许范围 6..32，改动后重启游戏。更大前探能降低目标方向量化，但不保证狭窄地形更好；先测试默认值再决定是否调整。记录问题时同时说明游戏版本、场景、走路/跑步和配置值。

## 七、dev3 用户反馈

2026-09-28 用户确认“操控比之前顺滑多了”，要求暂时保留当前手感，完整功能完成后再精调。该反馈不自动扩大为双版本所有场景验收。后续拟研究前方扇区、目标指向及换图机制；本版尚未实现 90 度扇区或自动换区。

## 八、技能方向重大失败反馈（2026-09-29）

用户报告技能仍朝真实鼠标方向释放。将“能发动动作”与“动作目标方向正确”分开：后者当前不通过。代码评估发现未覆盖的鼠标世界点读取和最多五周期重试重新取鼠标目标的路径；具体技能的实际触发链仍待动态定位。本轮未生成修复版。

后续必须加入鼠标位置无关性测试：手柄与角色状态保持相同，把鼠标置于左/右/后方，分别检查首发、无目标释放、RT 切技能、重试和续段，鼠标模式再单独验证原版行为。

> 用户已补充：技能方向跟随鼠标在本体和外传均出现，表现涉及其所见所有技能，且角色发动时会转向鼠标。按两作共性转向/目标来源错误处理，不能只修个别技能或只验证缓冲重试。
