# 手柄实机验证说明

适用版本：EDSlashController v0.1-dev2 调查与操作修正版。必须分别测试非 Steam 本体 1.05 与外传 2.01；两作使用同一个 ASI 和 SDL3.dll。Steam 和改版 EXE 尚未列入本版运行基线。

## 一、部署与记录

将 release 中的 `EDSlashController.asi`、`EDSlashController.ini`、`SDL3.dll` 放在游戏 ASI 加载器实际加载的同一个目录。ASI 加载器使用游戏现有安装，本项目未另带或下载加载器。

暂时移出旧手柄实验 ASI，防止多个手柄插件同时注入。首次测试先验证独立手柄，再验证与主插件 BladeSwordQOL 同时加载。主插件内部 EventBus 并未跨 DLL 共享，不能省略共存测试。

日志位于插件旁的 `EDSlashController.log`，每次启动覆盖旧内容。测试完一作后先另存该次日志，再测试另一作，避免覆盖对照。日志应显示对应非 Steam Profile、输入桥安装、SDL 初始化、手柄连接；首次连接或切换模式后请松开所有摇杆、扳机与按钮。

## 三、本版不能当成已完成的功能

- 全菜单几何导航、格子导航、标签页和焦点区域切换、特殊操作以及导航框。
- 方向闪避、LT+ABXY 两次按键必杀技。
- 跳跃/瞬移等动作的长按目标外扩、松开执行；本版 X/Y 仅走普通动作释放。
- 角色专属特殊动作自动识别；RT+L3/R3 默认未配置。
- 连续招式内部的精确重定向、受击震动。
- 静态交互物的独立空间枚举；本版仅复用鼠标已有静态候选，动态 NPC 则做附近筛选。
- 手柄图标、游戏内模组设置页及 Steam 兼容。

尚未覆盖的菜单可以切换鼠标模式完成操作，但不能因此把该菜单的原生手柄导航标为通过。

## 四、dev2 当前重点

本轮先测试进入地图后左摇杆走路、松杆停止、靠近 NPC 按 A、选择好左右手动作后按 X/Y。不要用菜单 Enter 是否响应代替世界操作验收。

若仍无反应，保存本次 `EDSlashController.log`，重点看 `[输入链]`：按键/摇杆是否改变、层是否一直为菜单、门编号与界面 ID、原生帧计数是否增长；再看是否出现 `[移动]`、`[调查]`、`[动作]`。这些字段用于定位阻断点，提交日志并不等于动作执行成功。
