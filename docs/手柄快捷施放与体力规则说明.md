# 手柄快捷施放与体力规则说明

> 文档维护约定：本文按主题维护当前有效的技术正文，不再追加版本更迭、日期同步或发布补丁章节。版本变化、旧版散列、阶段测试与用户反馈统一记入[版本与更新记录](版本与更新记录.md)；技术结论变化时直接修订对应正文。

## 快捷技能、投掷与套组

RT+技能键读取当前角色原游戏绑定或角色独立TOML绑定，直接请求selector/手侧，不调用左右手setter、不要求再按Y。资格、硬直、消耗与有限五周期重试保留。默认14槽顺序、来源与自定义表见《统一配置与基础迁移说明.md》。

RB+六槽键读取HUD逻辑槽6..11对应物品，核对数量并按原投掷选择规则生成物品值+10000的选择码。不能调用会切换/取消右手选择的旧投掷快捷执行器。库存消耗与弹道由原版处理。

Y持有四套自定义连招的选中编号、步骤和代次；实际成功创建该套步骤才推进。技能/投掷不会推进Y，切组旧通知不能推进新组。LT+上/右/下/左切第1/2/3/4套并回首项。X保留左键动作，LB药品沿用原业务。

## 体力配置与计算

EDSlash.toml的gameplay.combat含charge_guard_on_hit/free_run，gameplay.stamina含guard_mode、guard_percent、recovery_mode、recovery_percent。

防御original模式保留角色原周期规则；percent模式按当前最大体力计算，恢复guard模式跟随实际防御幅度，percent模式独立计算。百分比0..100.00、最多两位小数，内部用百分之一整数。最大体力200时12.50扣25、5.25回10.5；不按剩余体力或原周期倍数算。通过角色虚表+0x80读当前最大体力，原体力调整函数处理上下限和耗尽。

开启受击扣费时不在空防御期间周期扣费；攻击只有实际减少敌方生命才恢复，挥空、零伤害、治疗和NPC不计。真实受击入口从虚表+0x6C定位，不能因Getter相同猜入口。关闭该规则恢复原版周期防御并停止附加命中恢复。free_run开启时全程免跑步体力，不按追击敌人判定。

原最低5点防御门和特殊穿防保留，不把全向格挡当永久免伤。防御诊断用于区分姿态、体力与攻击反应。

## 请求来源与验证

pending请求与已提交issued动作分别记录来源；不能只用右手布尔值区分技能、套组、投掷。有限缓冲是状态受限重试，不是无限预输入或强制取消原动作。普通手柄不以鼠标位置组织技能。

离线宿主验证资格、库存、同槽连投、空槽、Y隔离、原受击网关、HP差、幅度与上限；实际全技能、真实消耗及全部配置仍按实机覆盖判断。阶段测试数和反馈只记在更新记录。方向闪避、全向格挡、必杀和图标当前机制见对应专题正文。
