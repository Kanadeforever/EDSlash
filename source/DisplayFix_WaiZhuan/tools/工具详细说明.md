# 工具详细说明

## verify_build.py

只读检查最终 `DisplayFix.asi`、INI、源码边界和仓库编码规范，不运行游戏也不改游戏文件。

当前检查：

- PE32 / i386；
- DLL 标志；
- 非零入口点；
- `InitializeASI` 导出；
- Import Directory=0；
- `DisplayFix.ini` UTF-8 无 BOM；
- 仓库文本 UTF-8 BOM=0；
- BAT 必须 UTF-8 无 BOM + CRLF；
- `build.bat` 禁止递归误选 ARM64 LLVM，并要求固定 x64 LLVM 回退；
- `Font.FixDPI` 必须在 `Display.Enable` 提前退出前独立执行；
- clean1 必须存在 test4 的 `steam_create_file_a_shim` / `install_steam_resjm_language_shim`；
- clean1 必须只改 CreateFileA 低层调用点，不能覆盖 `0x005511E4` IAT；
- clean1 不允许混入 test4~test9 的影片/OpenGL实验入口：DirectShow aspect patch、ActiveMovie watchdog、MovieManager takeover、teardown bypass、worker quarantine 等。

这个验证器的作用是防止以后整理源码时不小心把已经失败的实验重新带回纯净基线。

## verify_compatibility.py

对一个或多个外传 `ComeOn.exe` 做只读结构验证。验证依据是机器码内容、调用关系和 vtable 结构，不使用整个 EXE SHA-256 白名单。

当前检查：

- 字体 DPI 原始/已修复上下文；
- 显示模式函数和三处分辨率逻辑；
- 同 mode + force=0 早退；
- 原版前端 mode 4；
- Strategy enter/exit callsite；
- JMM 选择器、UI 广播和资源路径链；
- 主 HUD 构造/vtable/layout；
- 顶部 0x0B / 0x0E 原版窗口分支；
- world press / global release 输入链；
- clean1 Steam 多语言兜底所依赖的唯一 CreateFileA 调用上下文，并报告实际 VA。

它不会验证 Steam launcher 或 OpenGL 实机稳定性，也不会把 test3~test9 影片实验当成当前运行要求。

## verify_compatibility.bat

Windows 拖拽入口。把一个或多个 `ComeOn.exe` 拖到 BAT 上，会依次调用 Python 验证器。

BAT 同样必须 UTF-8 无 BOM + CRLF。

## FontFix_WaiZhuan

`source\FontFix_WaiZhuan\apply_dpi_font_fix.py` 与 `apply_fix.bat` 是独立 96 DPI 字体补丁器。它按机器码上下文识别字体 DPI CALL，可以脱离 DisplayFix.asi 使用。算法在 clean1 没有变化。
