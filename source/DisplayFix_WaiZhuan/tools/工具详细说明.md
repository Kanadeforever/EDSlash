# 工具详细说明

## verify_build.py

只读验证编译出来的 `DisplayFix.asi` 与仓库构建规范：

- PE32 / i386；
- DLL 标志；
- 非零入口；
- `InitializeASI` 导出；
- ASI 自身 Import Directory=0；
- `DisplayFix.ini` UTF-8 无 BOM；
- 仓库文本禁止 BOM；
- BAT 必须 UTF-8 无 BOM + CRLF；
- `build.bat` 不得递归误选 ARM64 LLVM；
- release 必须由构建脚本重新生成。

## verify_compatibility.py

对外传 `ComeOn.exe` 做只读结构验证，不修改 EXE。

当前检查：

- 字体 DPI 原始/已修复上下文；
- 显示模式函数和三处分辨率代码；
- 同 mode + force=0 早退；
- 原版前端 mode 4；
- 外传 Strategy enter / exit callsite 与目标函数；
- JMM 选择器和资源链；
- 主 HUD 构造/vtable/layout；
- 0x0B / 0x0E 目标窗口分支；
- world press / global release 输入链。

验证依据是机器码内容和调用关系，不是整个文件 SHA-256 白名单。因此附件中的历史宽屏 EXE 只要目标结构还在，也能通过。

## verify_compatibility.bat

Windows 拖拽入口。把一个或多个 `ComeOn.exe` 拖到 BAT 上即可依次调用 Python 验证器。

BAT 同样必须 UTF-8 无 BOM + CRLF。
