## 产物校验

verify_build.py解析真实PE导出/导入/重定位与标准TOML；runtime_sections/verify_variants比较非调试段RVA/虚拟大小/字节，verify_debug_info检查debug信息与发行剥离。文件内名称不代替实际GetProcAddress，工具不能证明Hook语义或实机。

## EXE兼容复核

统一 EXE 兼容检查入口。先按 PE 头识别 Profile，再分派到：

```text
source\tools\compat\compat_daojian.py
source\tools\compat\compat_waizhuan.py
```

子验证器只读 EXE，核对 DisplayFix 内容签名、调用关系、vtable 与 UI 结构；保留的历史结构不代表当前 ASI 安装对应旧 Hook。统一入口只分派 EXE；Steam ComeOn.dll 要直接调用 tools/compat/compat_waizhuan.py。QOL 三入口由 QOLModule 在运行时核对，不由此工具完整验证。

## 永久字体工具

工具路径：

```text
source\tools\font_fix\DaoJian\apply_dpi_font_fix.py
source\tools\font_fix\DaoJian\apply_fix.bat
source\tools\font_fix\WaiZhuan\apply_dpi_font_fix.py
source\tools\font_fix\WaiZhuan\apply_fix.bat
```

一般运行用ASI的`font.fix_dpi=true`并保留官方EXE。永久工具默认输出`.workspace/release/字体修复/*_DPI_FontFix.exe`；`--output-dir <目录>`可显式选择安全目录，解析目录链接后拒绝参考资料和覆盖输入。以xb独占创建，已有输出或链接不覆盖；只改目标CALL的6字节并重读比对，已修复输入不重复生成。派生EXE完整SHA改变，统一Controller会拒绝，不能无条件组合使用。0x5A才是LOGPIXELSY=90，0x48用于后续字体计算。`python source/tools/font_fix/test_font_fix.py`在.workspace临时目录回归四真实样本，不改输入。

## 原生动作只读研究

`source/tools/controller/trace_native_actions.py` 只读四份Steam／非Steam基线，验证冻结 SHA-256 后使用 pefile 与 Capstone 解码原生技能解析、执行、转向、历史回写、输入分发等已登记函数范围与基本块，并验证历史门初始值及各 6 处写入。依赖仅用于研究工具，正式构建仍使用 Python 标准库，不自动安装依赖。

从项目根运行：

```powershell
python source/tools/controller/trace_native_actions.py --baselines "参考资料/刀剑封魔录系列反编译资料库_v0.31/基线程序" --output "docs/证据/逆向分析/手柄原生动作拆分证据.txt"
```

只有两版全部校验和完整解码成功后才写输出。工具拒绝把输出写入只读参考资料或基线目录，不运行游戏、不修改 EXE、不安装 Hook。解码从已确认函数起点进行，不从任意地址猜指令边界。结果说明局部静态控制流，不证明实机触发频率或完整功能可用。

## 技能与日志只读研究工具

`source/tools/controller/trace_menu_pages.py --output docs/证据/逆向分析/手柄技能日志界面原始证据.txt`读取四份冻结散列的Steam／非Steam EXE，以标准库PE读取及Capstone解码虚表、技能主操作、日志编排、技能base更新调用、连招命中和绘制六列布局。Capstone仅研究时需要，构建不自动安装。输出参数必填，拒绝参考资料目录；输出UTF-8无BOM与CRLF，保留机器字节。工具不启动/注入游戏、不读写存档。地址和栈参数还由双样本槽/CALL检查和32位宿主回放补证，静态证据不是实机验收。

加`--learning --output docs/证据/逆向分析/手柄必杀自动学习原始证据.txt`只导出原主操作、学习函数、同组第四记录自动补入、已学资格和必杀说明分支；先解码两作原学习CALL，核对480DA0／48FBD0目标。不同研究范围单独存证，不覆盖既有原始TXT。test_menu另覆盖原删除后的同帧焦点补位、末项回退、空清单、原拒绝和按住不连删，必杀自动学习没有伪造宿主验收。

加`--grid --output docs/证据/逆向分析/手柄背包储物箱原始证据.txt`只读导出两作背包/储物箱原详情、BC物理路由门、格号和主/辅助操作、24像素10列命中及持有物品交换。--grid与--learning不能同时使用，输出仍拒绝参考资料，正式构建不依赖Capstone。

加`--regions --output docs/证据/逆向分析/手柄多区域与持有图样原始证据.txt`读取六区域扩展业务、根工厂登记ID及软件图样原持有分支减半尺寸。三个研究范围互斥，旧证据不覆盖；本体/外传新虚表和商店/镶嵌私有坐标调用由verify_profiles.py解码复核。test_menu新增辅助页不在普通链/属性13=0、六区域循环、隐藏过滤、原特殊槽业务、商店模式和确认、空存档尾页及外传标题图样差异，所有非标题场景同时回放两作。

## 构建配置同步

sync_config.py不另建构建入口，唯一构建说明仍为source/readme.md。构建器读取生产生成模板和全部目标配置，解析成功后只补模板缺失键：存在段在段末插入，不重复声明；缺失段在文件末追加，复制新键的说明注释。旧角色绑定和其它已有值通过全叶子快照逐一复核；合并后标准tomllib再解析并核对模板键完整。无需补键时保持原字节，补键时UTF-8无BOM与CRLF；同目录临时文件原子替换，外部改动检测失败则拒绝写入。语法损坏、重复定义或无法安全扩展的表不会覆盖；此工具不替代运行时的类型/范围/未知键检查。

发行与debug每次正式构建都同步，发行先剥离再默认UPX --best --lzma；release/upx为同一压缩副本并同步配置。checks-only运行回归但不写发布配置。Python测试用.build临时目录，验证真实模板max_distance补入、已有free_run自定义值/角色绑定/注释保留、幂等、缺文件生成、语法失败和并发修改保护。构建报告记录补入键，不复制到任何游戏安装目录。

test_inspect.c真实链接Inspect/Game，使用局部地图格、句柄与原调用包装回放，检查扇区/静态/去重/原悬停；不运行真实脚本。菜单工具增加原删除对话与Cursor绘制两个分支，使用自有对象，不读取或删除个人游戏存档。

trace_interaction_ui.py --output <证据路径>只读四份冻结EXE，验证SHA并由Capstone从真实入口导出静态返回链/NPC对话。输出拒绝参考资料目录；正式构建不依赖Capstone。当前新增证据为[手柄静态资格与对话原始证据.txt](../../docs/证据/逆向分析/手柄静态资格与对话原始证据.txt)。

trace_interaction_ui.py现可导出原鼠标按下写2C4及单句Tick/Space额外滚动，证据另存[手柄对白滚动与鼠标配对原始证据.txt](../../docs/证据/逆向分析/手柄对白滚动与鼠标配对原始证据.txt)，不改旧TXT。

设置批量保存回归位于test_config.c：多项参数／双角色技能槽单次保存、非法后项不保存前项、重复字段／槽位拒绝、外部修改拒绝、保存与FRAME／IDLE／RESTART生效快照分离。仅用根.build内测试TOML，不改玩家配置。

设置模型回放包含双列末项／分页焦点保持、滚动、说明不阻挡导航、草稿取消／完整保存／保存失败保留草稿；控制回放包含仅世界层改绑、菜单A/B交换、RT及物理救援保留。框架不运行游戏窗口，原绘制和入口实机仍需后续。
