# 随机姓名离线测试

在项目根目录执行：

```text
python source/tools/qol/test_random_name.py
```

需要Python 3及Visual Studio/Build Tools的桌面C++、x86工具和Windows SDK。测试通过source/tools/toolchain.py自动探测原生MSVC Win32；可用EDSLASH_VS指定安装根，不依赖个人路径记录。

测试先检查内置词库的去重、分类隔离及 GBK 无损编码，然后直接编译并运行 `test_random_name.c` 引用的生产 `RandomName.c`。编译明确使用 UTF-8 源码和执行字符编码，并把编译警告视为错误。输出位于根目录 `.build/qol/random_name_test.exe`。

测试不构建 ASI、不写发行目录、不启动或读写游戏。离线通过不证明游戏字体、窗口地址、原生文本接口或真实姓名长度正确。完整规则与后续接入边界见 `docs/文档/随机姓名功能与接入说明.md`。
